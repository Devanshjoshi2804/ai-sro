# Non-Worked Time report

This report provides details on the non-worked time (paid and unpaid) taken by a user. In addition, if a user is associated with a non-worked time bank, this report will also specify the non-worked time allotment still available for the user.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.
