# Count Back Adjustments report

This report displays, by count batch, the number of locations in which quantities were adjusted as a result of a count back. A count back occurs when an operator picks inventory from a location and, after the pick, is required to count the remaining inventory in the location. Count back counts can be configured to be required by user, location, pickable UOM, and item.

You can view the number of locations adjusted for each count batch.
