# Item Style Attributes

Items can be identified by color, fit, size, and style. You use the item style attributes configuration to define values for any of these attributes that your items require. For example, if you track items by color, you can define the colors that are available for selection.

After item style attribute values are defined, you use the item configuration to assign values to an item. You can then track, report on, or search for inventory using the attribute values that you defined. For example, these values can be displayed in inventory and item reports, and can be used to find matching inventory for the purpose of applying a hold or performing an inventory status change operation.

## Add or modify an item style attribute

1.  Select **Configuration > Inventory > Items > Item Style Attributes**.
2.  Perform one of the following tasks:
    -   To add an item style attribute, click **Add**.
    -   To modify an item style attribute, in the grid, click the code name.
    -   To copy an item style attribute, in the grid, select the check box next to the attribute, and then click **Copy**.
3.  Enter information in the following fields:
    
     
    | Field | Description |
    | --- | --- |
    | Attribute Category | Item attribute. You can define a value for the following attributes: color, fit, size, or style. |
    | Code Name | Code that represents the attribute value. The code may be any alphanumeric value that an item requires. For example, a manufacturer may use a code such as R-100 to represent the color Red. |
    | Code Description | Text that represents the attribute value. This is the value that appears in the application when the item attributes are displayed. It can be different from the code name. For example, if the manufacturer uses R-100 to represent the color Red, you may want to use Red for the code description that is displayed to users. |
    
4.  Click **Save**.

## Delete an item style attribute

When you delete an item style attribute, it is removed from the application and also removed from any items to which it had been applied.

1.  Select **Configuration > Inventory > Items > Item Style Attributes**.
2.  In the grid, select the check box next to the item style attribute to delete.
3.  Click **Delete**. A confirmation message is displayed.
4.  Click **OK**.
