# Safe extensions enforcement policy

The Safe extensions enforcement (EXTENSIBILITY/UPDATE-SAFETY/ENFORCE) policy indicates the Update Safety mode value set for the application. In the Console, the Update Safety page displays reports published by a runtime analysis tool that can be configured to report or prevent the running of custom MOCA extensions that violate update safety rules. Update safety rules define the appropriate use of extensions to ensure that your environment can be more seamlessly upgraded to the next major version.

The following DETAILS field configures this policy:

-   **Return String 1**: Specifies the Update Safety mode. Valid values are OFF, ANALYSIS, and FILTER. The default value is OFF.
    
    **Note**: It is recommended that you use the Console Update Safety page to change this value. See the _Supply Chain Execution Applications Console User Guide_.
