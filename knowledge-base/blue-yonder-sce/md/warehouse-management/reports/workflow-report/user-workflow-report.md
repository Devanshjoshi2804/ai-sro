# User Workflow report

Lists the information needed by a user who is validating the identification or picking work of other users. After printing this report, a user can write his or her name on the Inspector line and then use the information on the report to compare against the inventory that the other user has identified or picked.

The report includes the following information:

-   User ID of the user who identified or picked the inventory
-   Inventory ID
-   Date deposited for validation

In addition, a User Workflow report for validating identification work includes planned inbound order line information, and a User Workflow report for validating picking work includes order line information.
