# Warehouse Performance report

This report provides a summary of the payroll information for the specified date range. Payroll information can be grouped by user, work area, shift, or a variety of other settings.

**IMPORTANT**: If you want to post the Warehouse Performance report output in a public place, then for confidentiality purposes it is recommended that you use a grouping other than User. The User grouping will display the user name and user ID information along with the amount of pay and number of hours worked for the user.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.
