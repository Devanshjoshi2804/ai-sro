# Check In

The Check In page is accessible from the following modules: **Receiving**, **Shipping,** or **Yard**.

You use this page to perform the following tasks:

-   Check in transport equipment and assigned tractor for an expected appointment
-   Check in transport equipment without an appointment

After you select an appointment or specify the equipment to check in without an appointment, the following information is displayed:

-   **Transport Equipment**: Used to view or edit the details of the equipment to be checked in; or if one is not assigned, you can add transport equipment. You can also add and assign tractor to this transport equipment.
-   **Inbound Shipment** or **Load**: Used to add or delete an inbound shipment (receiving equipment) or load (shipping equipment) for the transport equipment.
-   **Locations**: Used to view and select a location at which to check in the equipment. You can select a dock door or yard location from a list of recommended doors or available yard locations.
