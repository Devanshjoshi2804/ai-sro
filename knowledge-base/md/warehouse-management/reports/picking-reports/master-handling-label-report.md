# Master Handling Label report

This report displays the order information for a master handling unit. A master handling unit is a handling unit that contains slots to which inventory is picked for sequenced orders. This report is typically printed as a label and affixed to the handling unit.

You can limit the information on the report by List ID (Work Assignment).

This report includes the following details:

-   Header information
    -   Work assignment barcode (which an operator can scan to begin the work assignment)
    -   Item family sequence
    -   Handling unit type
    -   Closed time
-   Detail information
    
    **Note**: Detail information is only printed if the item family is configured to release all work assignment picks when the work assignment is entirely allocated and ready to release. If the application is configured to release picks as they are allocated, then only the header information is provided on the report.
    
    -   Slot
    -   Item
    -   Planned order sequence
    -   Ordered quantity
    -   Total quantity
