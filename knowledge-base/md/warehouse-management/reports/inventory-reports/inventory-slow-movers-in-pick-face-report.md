# Inventory (Slow Movers in Pick Face) report

This report displays a list of locations within case and piece pick zones containing inventory, and the last date the locations were accessed for any type of activity.

The report includes the following details:

-   Item client
-   Area
-   Storage location
-   Last activity date and time
-   Item
-   Unit quantity
-   Committed quantity
-   Pending quantity
