# Work Orders

The Work Orders page provides visibility to the work orders that are created within the facility. A work order is an internal order used to find, allocate, and deliver items to a work-in-progress location where the items are processed. When you click on a work order, the work order details are displayed, and you have access to the following tabs:

-   **Summary**: Provides general information about the work order and the production progress.
-   **Order Lines**: Displays the work order lines (component item) details for the work order, and enables you to perform tasks such as requesting additional components.
-   **Picks**: Displays the allocated pick work for the work order and enables you to perform tasks such as cancel and release picks.
-   **Shorts**: Displays the work order lines that were allocated short and also enables you to cancel the associated replenishments.
-   **Pending Replenishments**: Displays the replenishment pick work for the work order and also enables you to cancel the replenishments.
-   **Cross Dock**: Displays the cross docking work for the work order and also enables you to cancel the cross docking work.
-   **Picked**: Displays the completed pick work for the work order.
-   **Produced**: Displays the finished items in the production line.
-   **Waiting Orders**: Displays shipments and orders that are to be fulfilled with the work order's top-level item or component items.
