# Shipped Handling Units report

This report displays summary information about the serialized and non-serialized assets that were shipped for a specified warehouse, client, shipment, handling unit type, and handling unit identifier.

The report includes the following details:

-   Warehouse
-   Handling unit client
-   Shipment
-   Address name
-   Handling unit type
-   Handling unit ID
-   Handling unit status
-   Empty
-   Quantity
