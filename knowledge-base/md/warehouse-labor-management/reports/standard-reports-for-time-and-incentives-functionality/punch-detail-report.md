# Punch Detail report

This report provides the users’ punch hours for the period specified, as well as details of the clock punches per day. Records are grouped by user and totaled for the date range specified.

**Note**: The Punch Detail report calculates the users' punch hours based on the clock out time minus the clock in time. Because the Time and Incentives functionality calculates pay based on timeblocks, this report may not accurately reflect the amount of hours for which the user is paid. For example, if a user has an unpaid adjustment added into their day, it will not be reflected in the Punch Detail report. It is recommended that you generate payroll and then run the Payroll Register report to view the users' total paid hours for the pay period.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.
