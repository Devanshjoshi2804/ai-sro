# Production Line Schedule report

This report displays a list of the planned work orders and their assigned production lines. After you select the report, you can limit what displays in the list by entering a specific production line, work order number, beginning date, or ending date.

You can also limit the report to list only those work orders that are either started or not started. You can specify whether the report is to include unavailable time assignments.

The report includes the following details:

-   Begin and end date of the report
-   Warehouse
-   Production line
-   Plan type
-   Work order number
-   Client
-   Top-level item
-   Work order quantity
-   Production quantity
-   Processing priority
-   Plan sequence
-   Scheduled begin date
-   Scheduled end date
-   Work order status
-   Started Flag
-   Date due
