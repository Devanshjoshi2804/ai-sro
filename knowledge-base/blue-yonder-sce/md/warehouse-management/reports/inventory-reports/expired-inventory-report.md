# Expired Inventory report

This report displays date-tracked inventory that will expire within a specified time period. You can limit the report by from and to expiration dates, item, lot, origin code, supplier, revision level, and aging profile name.

The report includes the following details:

-   Item and item description
-   Area
-   Item client
-   Supplier
-   Storage location
-   Lot
-   Revision level
-   Supplier
-   Origin code
-   Aging profile name
-   Expiration date
-   Unit quantity
