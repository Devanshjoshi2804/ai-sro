# Shipment Outbound Order Status report

This report displays an alphabetical list of item that have been allocated for shipments.

The report includes the following details:

-   Item client
-   Item
-   Carrier
-   Quantity of the item that has been:
    -   Ordered
    -   Reserved
    -   Picked
    -   Shipped
    -   Back ordered
