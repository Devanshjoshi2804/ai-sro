# Hardware

Hardware refers to the printers, RF devices, voice devices, and workstations used in warehouse operations. Every piece of hardware that you want to use with the application must be configured.

As inventory comes into the warehouse and is moved from one location to another, the application tracks the user who moved the inventory and the device (hardware) used to move the inventory. In addition, printers must be defined so that report and label printing can take place as needed during operations such as picking, packing, and shipping.
