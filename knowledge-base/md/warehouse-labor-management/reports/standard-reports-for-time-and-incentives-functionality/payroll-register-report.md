# Payroll Register report

This report enables payroll administrators to view detailed payroll information for each user during the specified date range. For example, this report can be used to assist a payroll administrator to validate user payroll information against a host payroll system. User payroll information can be grouped by work area, shift, or a variety of other settings.

**IMPORTANT**: The Payroll Register report displays the user name and user ID; therefore, the report output from the Payroll Register report should not be displayed in a public place. If you want to post payroll information in a public place, then use the Warehouse Performance report instead.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.
