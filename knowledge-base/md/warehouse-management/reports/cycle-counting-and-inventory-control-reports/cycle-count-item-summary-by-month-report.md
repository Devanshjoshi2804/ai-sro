# Cycle Count Item Summary (by Month) report

This report displays the locations and items, grouped by month, that were counted and adjusted for the beginning count date that you specify. The report displays count information for counts that have been processed as complete.

The report includes the following details:

-   Item client
-   Count month and year
-   Item
-   Number of locations counted
-   Number of locations adjusted
-   Percentage of locations adjusted
-   Item value and currency before count
-   Item value and currency after count
-   Net adjusted item value and currency
-   Absolute adjusted value and currency
