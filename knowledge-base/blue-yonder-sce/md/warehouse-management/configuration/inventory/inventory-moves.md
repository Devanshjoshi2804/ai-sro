# Inventory Moves

An inventory move occurs when inventory is transferred from one location to another. Inventory moves can be user-initiated or application-initiated.

When you configure inventory moves, you define consolidation criteria, movement restrictions, and other movement attributes. You can also define how the application releases directed work for stock transfers.
