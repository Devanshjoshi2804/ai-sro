# Alternate Item Types

An alternate item type is a type of identifier that can be used to define alternate item numbers (identifiers) for an item. The use of alternate item numbers is optional.

After you have assigned an alternate item type and identifier to an item, users can enter or scan the alternate identifier instead of the original item identifier to track the item.

When you define an alternate item type, you specify the name of the type and a description. After you define an alternate item type, you can assign it to an item along with an identifier based on that type.

Alternate item types are used, for example, to group identifiers such as Universal Product Codes (UPC), Uniform Council Codes (UCC), or display items (identifiers that provide an easily identifiable description of the item instead of a code, and which are displayed to the user in place of the master item).

## Add or modify an alternate item type

1.  Select **Configuration > Inventory > Items > Alternate Item Types**.
2.  Perform one of the following tasks:
    -   To add an alternate item type, click **Add.**
    -   To modify an alternate item type, in the grid, click the alternate item type.
3.  In the **Alternate Item Type** and **Description** fields, enter the values.
4.  Click **Save**.

## Delete an alternate item type

You cannot delete an alternate item type that is assigned to an item.

1.  Select **Configuration > Inventory > Items > Alternate Item Types**.
2.  In the grid, select the check box of the alternate item type to delete.
3.  Click **Delete**. A confirmation message is displayed.
4.  Click **OK**.
