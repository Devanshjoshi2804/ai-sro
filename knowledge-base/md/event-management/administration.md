# Administration

In addition to the tasks that typical users can perform (see [Task flow](events.md)), users with access to the Administration page can perform the following administrative tasks:

-   View, release, or delete held alerts. See [Held alerts](administration/held-alerts.md).
-   View all or a subset of the alerts that currently exist in the application, and then make changes to an alert, its event, or event subscribers to resolve alert issues. See [Find alert](administration/find-alert.md).
-   Maintain events by modifying events sent to Event Management by an integrated application or manually adding new events. See [Event configuration](administration/event-configuration.md).
-   Configure the general Event Management instance attributes. See [System configuration](administration/system-configuration.md).
-   Configure event subscriptions, out of office settings, and notification accounts for another user. See [User configuration](administration/user-configuration.md).
-   View all or a subset of the event subscriptions that currently exist in the application and manage event subscriptions to resolve subscription issues. See [Event subscribers](administration/event-subscribers.md).

After completing the initial configuration of the Event Management instance (see Event Management Configuration Guide), the administrative tasks are typically only performed on an as-needed basis.
