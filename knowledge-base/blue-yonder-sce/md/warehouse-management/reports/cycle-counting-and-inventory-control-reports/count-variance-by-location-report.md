# Count Variance (by Location) report

This report displays, by location, cycle counts that were performed and for which the amount counted did not match what the application expected. You can limit the report by storage location, item client, and begin and end location.

The report includes the following details:

-   Storage location
-   Work area and work zone
-   Count batch
-   Count date
-   Item
-   Item client
-   Item description
-   Lot
-   Expected quantity
-   Unit of measure
-   Count quantity
-   Variance
-   Total counts completed
-   Grand total
