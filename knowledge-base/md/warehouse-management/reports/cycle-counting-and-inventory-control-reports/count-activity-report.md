# Count Activity report

This report displays detailed information about the counting activities in your facility. You can limit the report by count success, item, location, count type, count user, beginning count date, and ending count date. For example, you can view the following information:

-   From count date
-   To count date
-   Count date
-   Count batch
-   Location
-   Item and item description
-   Item client
-   Generation code
-   Count mode
-   Count type
-   Count user
-   Count quantity
-   Expected
-   Unit cost
-   Total unit cost
