# Configuration - Picking

The Configuration page in the Picking module provides access to the configurations relevant for picking operations. You can modify configurations as necessary to accommodate the picking process for your warehouse. After you access the Configuration page (select **Picking > Configuration**), see the following topics that support the available picking configurations:

**Note**: The configurations available in the Picking module may differ from those that are available in the Configuration module.

-   [Allocation](../configuration/outbound/allocation.md)
-   [Picking](../configuration/outbound/picking.md)
-   [Movement](../configuration/inventory/movement.md)
-   [Replenishments](../configuration/inventory/replenishments.md)
-   [Locations](../configuration/warehouse/locations.md)
