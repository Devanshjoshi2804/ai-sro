# Cycle Count Detail (for Dates) report

This report displays all cycle count and audit count information from count batches that have been completed, and have been performed in the facility for a range of dates, item client, or both that you specify.

The report includes the following details:

-   From count date
-   To count date
-   Item client
-   Count date
-   Storage location
-   Item
-   Unit quantity
-   Count user
-   Discrepancy
-   Count quantity
-   Whether an audit was generated
-   Total number of counts completed
-   Total number of audits generated
