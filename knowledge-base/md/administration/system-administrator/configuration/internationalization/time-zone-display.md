# Time Zone Display

You use Time Zone Display to view time zones available in the application. Time zone values listed can be selected as a preferred time zone or associated with the address of a partner, such as a client or customer.

Date and time information is displayed in the web client using the default system time zone or a preferred time zone. Users can change their displayed time zone from the user name drop-down list in the application title bar. See [Title bar](../../../../get-started/user-interface.md).

## View time zones

1.  Select **System Administrator > Configuration > ** **Internationalization > Time Zone**.
2.  View the information in the [Time Zone Display fields](#Time_Zone_Display_fields).

## Time Zone Display fields

 
| Field | Description |
| --- | --- |
| DST Time Zone Code | Acronym that represents the daylight savings time (DST) time zone description, such as PDT for Pacific Daylight Time or CDT for Central Daylight Time. DST time zones are used if the time zone adjusts for DST. |
| DST Time Zone Description | Name of the time zone indicating daylight savings time. |
| DST Time Zone Offset | Positive or negative number indicating the difference in hours or fractional hours between the DST time zone and the Greenwich Mean Time/Coordinated Universal Time (GMT/UTC) time zone. |
| DST Time Zone Offset Description | Positive or negative number indicating the difference in hours or fractional hours between the daylight savings time zone and the Greenwich Mean Time/Coordinated Universal Time (GMT/UTC) time zone. |
| Detailed Description | Description of the time zone that further defines the time zone. |
| Description | Description of the time zone. |
| STD Time Zone Code | Acronym that represents the stored time zone description, such as PST for Pacific Standard Time or CST for Central Standard Time. |
| STD Time Zone Description | Name of the stored time zone. |
| STD Time Zone Offset | Positive or negative number indicating the difference in hours or fractional hours between the time zone and the Greenwich Mean Time/Coordinated Universal Time (GMT/UTC) time zone. |
| Time Zone Code | Unique identifier for a time zone. A time zone is a geographical area that uses the same local time. |
| Win32 Time Zone Map | Time zone code used by Microsoft Windows. |
