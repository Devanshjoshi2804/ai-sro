# Data Protection

Data protection settings are used to remove personal information as data is processed and archived. Specifically, you can enable the following settings:

-   Whether the application clears driver name and driver license number from transport equipment details when the equipment is checked out
-   Whether the application clears personal information when archiving data, such as names and addresses of customers, suppliers, clients, and users

## Configure data protection settings

1.  Select **Configuration > Advanced > Data Protection**.
2.  To clear the driver name and driver license number from the transport equipment details during check out, set **Clear Driver Data During Check Out** to **Yes**.
3.  To clear the personal information such as names and addresses of customers, suppliers, clients, and users, when archiving data:
    1.  Set **Clear Personal Data When Archiving** to **Yes**.
    2.  From the **Table** drop-down list, select **ADRMST**.
        
    3.  Under **Available Table Columns**, select the check box next to the column names that apply.
4.  Click **Save**.
