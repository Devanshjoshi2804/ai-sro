# Distribution Exception report

This report displays the distribution exceptions that either exist or have been resolved within your facility. You can limit the report building, area, location, LPN, item, and resolved status.

The report includes the following header information:

-   Location
-   Exception
-   LPN
-   Area
-   Reported quantity
-   Item
-   Building
-   Expected quantity
-   Item client
-   Resolved flag

The report includes the following details:

-   Transaction date
-   Activity code
-   User
-   Order
-   Carrier
-   Transport equipment
-   Item
-   Lot
-   Revision level
-   Item client
-   Origin code
-   Quantity
-   Catch quantity
-   Footprint code
-   Unit of measure
-   Storage location
-   LPN
-   Case identifier
-   Piece identifier
-   Zone
