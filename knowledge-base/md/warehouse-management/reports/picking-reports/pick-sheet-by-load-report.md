# Pick Sheet by Load report

This report, for paper-based picking, displays all of the picks associated with a particular load. You can limit the report by load, outbound order, source area, source work zone, source location, destination area, ship to (destination) work zone, destination location, shipment, work task, schedule batch, ship-to customer, work order, work order revision, comment, item, and label batch.

The report includes the following details:

-   Client
-   Comment
-   User
-   LPN
-   Order
-   Work task (barcode)
-   Source location (barcode)
-   Destination location (barcode)
-   Item
-   Item client
-   Picking unit of measure (UOM)
-   UOM quantity
-   UOM of the next inventory to be picked
-   Load
-   Footprint code
-   Pick quantity
-   Lines
-   Pieces
-   Weight
-   Cube
