# WCS Inventory Discrepancy Display

You use the WCS Inventory Discrepancy Display page to view inventory discrepancies between a warehouse control system (WCS) and Warehouse Management. At a scheduled interval, based on configuration, Warehouse Management looks for the WCS inventory snapshot. When Warehouse Management compares the snapshot data and discrepancies exist, they are displayed on the WCS Inventory Discrepancy Display page.

You can configure the attributes expected from the WCS for comparison. For example, you can select the attributes that are used in the discrepancy comparison and the order in which the inventory snapshot considers the associated attribute setting in the discrepancy comparison. See [Inventory reconciliation settings for WCS integration](../configuration/integration/warehouse-control-system-integration/systems-and-settings-for-wcs-integration.md).

## View WCS inventory discrepancies

1.  Select **Inventory > WCS Inventory Discrepancy Display**.
    
2.  Enter search criteria to display discrepancy information.
    
3.  View information in the WCS Inventory Discrepancy Display fields.
    
4.  To view LPN details, click the LPN.
