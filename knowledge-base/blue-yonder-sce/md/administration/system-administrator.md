# System Administrator

The application's features and functions are dependent on customizable system-wide settings. You use the System Administrator pages to view and manage deferred executions, integration errors, authorization (for setting up users, roles, and permissions), configuration (for internationalization, policy, system, and variable settings), operational report displays, and reports/labels (their configurations, operations, and archives) within the web client.
