# Countries

Country information contains the standard format and codes for mailing, shipping, and telephone access for a particular country. International Standards Organization (ISO) codes supply the information required by certain shippers for inventory exportation.

## Add or modify a country

1.  Select **System Administrator > Configuration > ** **Internationalization > Countries**.
2.  Perform one of the following tasks:
    -   To add a new country, from the **Actions** drop-down list, select **Add**.
    -   To copy a country, in the grid select the check box next to the country, and then from the **Actions** drop-down list, select **Copy**.
    -   To modify a country, in the grid select the check box next to the country, and then from the **Actions** drop-down list, select **Edit**.
3.  Enter information in the [Countries fields](#Countries_fields).
4.  Click **Save**. A confirmation message is displayed.
5.  Click **OK**.

## Delete a country

1.  Select **System Administrator > Configuration > ** **Internationalization > Countries**.
2.  In the grid, select the check box next to the country.
3.  From the **Actions** drop-down list, select **Delete**. A confirmation message is displayed.
4.  Click **OK**.

## Countries fields

 
| Field | Description |
| --- | --- |
| **Country Name** | Name or code name of the country. |
| **Description** | Name of the country. |
| **Address Format** | Code that represents the address format used by the country. |
| **ISO Alpha-2 Code** | Two-digit alphabetic code assigned to the country by the International Standards Organization (ISO). |
| ISO Alpha-3 Code | Three-digit alphabetic code assigned to the country by the International Standards Organization (ISO). |
| ISO Numeric Code | Numeric code assigned to the country by the International Standards Organization (ISO). |
| Domestic Long Distance Access Code | Numeric code that must be used to place a domestic long-distance telephone call within the country. |
| International Access Code | Numeric code that must be used to place an international long-distance telephone call from within the country. |
| Country Phone Code | Numeric code that must be used to place a call to a phone number in this country from outside the country. |
| ConnectShip Country Name | Not currently used. |
| Postal Code Length | Number of characters that are allowed for postal codes used in the country. |
| Duty Country Code | Country code used for communication with Duty Management. Values are determined by HM Revenue and Customs. |
| Absolute Group | An identifier used by Blue Yonder product teams to indicate the product group that was responsible for loading data (in a particular row of a table). Standard group names include dcs\_data, mcs\_data, and sal\_data. This field is display only. |
| Duty Country Type | Indicates whether the country is part of the EU, UK, or other. Values are EU, UK, or blank (does not belong to EU). |
