# Item Family Groups

An item family group is used to organize similar item families. Typically, all of the item families within a group have the same material handling characteristics. You can use item family groups for filtering and reporting purposes, and as criteria, for example, for storage paths and work assignment rules.

## Add or modify an item family group

1.  Select **Configuration > Inventory > Items > Item Family Groups**.
2.  Perform one of the following tasks:
    -   To add an item family group, from the **Actions** drop-down list, select **Add**.
    -   To modify an item family group, in the grid, select the check box next to the group, and then from the **Actions** drop-down list, select **Modify**.
3.  Enter information in the following fields: 
    
     
    | Field | Description |
    | --- | --- |
    | Item Family Group | Unique identifier for the item family group. |
    | Description | Meaningful description that defines the item family group, such as the common characteristics of the item families or reason for grouping them. |
    
4.  Click **Save**. A confirmation message is displayed.
5.  Click **OK**.

## Delete an item family group

**Note**: You cannot delete an item family group that is assigned to an item family.

1.  Select **Configuration > Inventory > Items > Item Family Groups**.
2.  In the grid, select the check box next to the item family group.
3.  From the **Actions** drop-down list, select **Delete**. A confirmation message is displayed.
4.  Click **OK**.
