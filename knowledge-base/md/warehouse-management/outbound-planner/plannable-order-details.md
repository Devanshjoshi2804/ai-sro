# Plannable Order Details

You use the Plannable Order Details page to view information for the existing outbound orders in the application that can be planned into a wave. For example, the page displays when the order was downloaded or manually added, and when it was most recently modified.

## View plannable order details

1.  Select **Outbound Planner > Plannable Order Details**.
    
2.  View information in the following fields:
    

 
| Field | Description |
| --- | --- |
| Order | Unique number that identifies an order. An order is a request for a supply of material or product. |
| Client | Unique identifier for a client who is responsible for creating the order or work order. |
| Date Added | Date and time at which the order was downloaded from the host into the application. |
| Date Entered | Date and time at which the order was manually added by a user in the application. |
| Date Last Modified | Date and time at which the order was last modified. |
| Last Modified By | User that last modified the order. |
