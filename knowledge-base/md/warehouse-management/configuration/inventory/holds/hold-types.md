# Hold Types

A hold type is a category used to group holds that are similar, and typically identifies the purpose of the hold. You assign a type to a hold when you create the hold. The hold type is used for display and reporting purposes.

## Add or modify a hold type

1.  Select **Configuration > Inventory > Holds > Hold Types.**
2.  To add a hold type:
    1.  Click **Add.**
    2.  Enter information in the following fields:
        
        | Field | Description |
        | --- | --- |
        | Hold Type | Code that represents a category for holds. Typically, the hold type identifies the purpose of the hold. The hold type is used only for display and report purposes. |
        | Description | Long description of the hold type. This is the value that is available for selection from the Type drop-down list when defining a hold. |
        | Short Description | Brief description of the hold type. This is the value that represents the hold type on RF screens. |
        
    3.  Click **Save**.
3.  To modify a description, in the grid, click the description, and then enter your changes.
4.  To reorder the list, in the grid, select the hold type to move, and then drag it to the new location in the grid. The grid order determines the order in which the hold types are displayed to the user, such as from a drop-down list field.
5.  To translate the description or short description of the selected row for use in another locale:
    1.  Perform one of the following tasks:
        -   To translate specific rows, in the grid, select the check box of the rows, and then above the grid, click **Translation**.
        -   To translate all rows, above the grid, click **Translation**.
    2.  From the **Destination Locale** drop-down list, select the locale.
    3.  In the grid, select a translated description or short description, and then enter the new value.
    4.  Click **Save**.
6.  Click **Save**.

## Delete a hold type

1.  Select **Configuration > Inventory > Holds > Hold Types.**
2.  In the grid, select the check box next to the hold type to delete.
3.  Click **Delete**. A confirmation message is displayed.
4.  Click **OK**.
