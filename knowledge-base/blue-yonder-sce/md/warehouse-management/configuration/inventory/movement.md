# Movement

A movement path defines the stops between a source and destination zone that are required for all or specific inventory (depending on assigned criteria) as it travels through the facility.

You use the Movement pages to group the locations to and from which inventory can be moved, limit the use of a movement path to inventory that matches certain criteria, and reserve deposit locations for inventory that should be organized together in the same location (such as inventory that has the same carrier).
