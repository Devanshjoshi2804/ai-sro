# Putaway Work report

This report displays the putaway work information for a given piece of transport equipment. You can limit the report by inbound shipment, transport equipment, LPN, carrier, inbound shipment status, and inbound shipment location.

The report includes the following details:

-   Warehouse
-   Client
-   LPN
-   Item
-   Destination location
-   Location travel sequence
-   Destination work zone
-   Zone travel sequence
-   Destination work area
-   Inbound shipment
-   Yard location
-   Source location
-   Transport equipment
-   Carrier
