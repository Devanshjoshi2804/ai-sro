# Hold History report

This report displays historical hold information. You can limit the report by activity type, hold prefix, hold number, hold type, hold action by (user), item, lot, revision level, origin code, from or to inventory status, LPN, sub-LPN, detail LPN, LPN UCC, sub-LPN UCC code, reason code, and beginning or ending hold date.

The report includes the following details:

-   Item client
-   Hold date
-   Activity type
-   Hold prefix
-   Hold number
-   Reason code
-   Hold type
-   Hold action by (user)
-   Unit quantity
-   LPN
-   Sub-LPN
-   Detail LPN
-   LPN UCC
-   Sub-LPN UCC code
-   Item
-   Item client
-   Lot
-   Revision level
-   Supplier
-   Origin code
-   From and to inventory status
