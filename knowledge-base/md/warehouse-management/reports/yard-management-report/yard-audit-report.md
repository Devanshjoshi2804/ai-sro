# Yard Audit report

This report displays the transport equipment audits that occurred within a specified range of dates. You can limit the information that displays by specifying a beginning transaction date, ending transaction date, storage location, and a reason code.

The report includes the following details:

-   Warehouse
-   Transaction date
-   Source location
-   Result of the audit
-   Reason code
-   User
-   Device code
