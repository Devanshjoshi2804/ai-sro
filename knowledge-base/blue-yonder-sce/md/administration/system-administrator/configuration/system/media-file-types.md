# Media File Types

A file type is an extension, or suffix, appended to the end of the file name to indicate the format of the file. Each file type possesses characteristics that affect the way that file is saved or displayed. A media file type is a subset of file type that indicates an image, text, or digital document file.

The following file categories and media file types are currently supported:

**Note**: Media with an unsupported file type cannot be displayed or downloaded in the application. To add a new file type, contact your Blue Yonder project team.

-   **FILE**
    
    -   .doc
        
        **Note**: You must have Microsoft Word installed to view .doc files.
        
    -   .pdf
        
        **Note**: You must have Adobe Reader installed to view .pdf files.
        
    -   .txt
-   **IMAGE**
    -   .bmp
    -   .gif
    -   .jpg and .jpeg
    -   .png

## Add or modify a media file type

1.  Select **System Administrator > Configuration > ** **System > Media File Types**.
2.  Perform one of the following tasks:

-   To add a media file type, from the **Actions** drop-down list, select **Add**.
-   To modify a media file type, in the grid select the check box next to the file type, and then from the **Actions** drop-down list, select **Edit**.
-   To copy a media file type, in the grid select the check box next to the file type, and then from the **Actions** drop-down list, select **Copy**.

4.  In the **File Type** field, enter the extension of the file type.
    
5.  In the **Description** field, enter a description for the file type.
    
6.  From the **File Category** drop-down list, select either **FILE** or **IMAGE** to indicate the media classification to which the file type belongs.
    

**Note**: The **AUDIO** and **VIDEO** file categories are not supported.

8.  Click **Save**. A confirmation message is displayed.
9.  Click **OK**.

## Delete a media file type

**IMPORTANT**: When you delete a supported file type, you are longer be able to upload, associate, or view new media files with that file type.

1.  Select **System Administrator > Configuration > ** **System > Media File Types**.
2.  In the grid, select the check box next to the file type.
3.  From the **Actions** drop-down list, select **Delete**. A confirmation message is displayed.
4.  Click **OK**.
