# Inventory Analysis report

This report provides visibility into potential order allocation problems by comparing inventory that is actually ready to be allocated to inventory that has been reserved for orders. You can limit the report by outbound order, item, supplier, item type, and size. You can also select whether to show inventory details.

The report includes the following header information:

-   Order
-   Item client
-   Color
-   Client
-   Item type code
-   Size
-   Item
-   Style
-   Supplier
-   Fit

The report includes the following details:

-   Item
-   On-hand quantity
-   Ordered quantity
-   Reserve quantity
-   Match quantity
-   Excess order quantity
-   Excess inventory quantity
-   Pickface quantity
-   Inprocess quantity
-   Locked location quantity
-   Future ship quantity
-   Bad status quantity
-   Hold quantity
-   Balance quantity
