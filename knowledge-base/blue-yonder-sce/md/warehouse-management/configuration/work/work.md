# Work

Work management configurations define how the application manages directed work in the warehouse. The application uses permissions (based on the user and the user's device), proximity (user's proximity to the starting point of the work), and priority (in relation to other work pending in the queue) to calculate which piece of work is offered to a user who requests directed work.
