# Cartonized Pick report

This report displays the pick information for a carton. You can limit the report by carton number and sub-load UCC code.

The report includes the following details:

-   Client
-   Carton number
-   Sub-load UCC code
-   Carton type

For each carton, the report includes the following details:

-   Work task
-   Outbound order
-   Item
-   Item client
-   Source location
-   Picking UOM
-   Lot
-   Origin code
-   Revision level
-   Supplier
-   Footprint code details
-   Pick quantity
-   Applied quantity
-   Remaining quantity
