# Preferred Methods report

This report enables you to print only the preferred method details of a flowchart instead of all of the details associated with that flowchart. You can use this report to coach, counsel, or train on a preferred method. The Preferred Methods report also enables you to create an observation form that you can use as a handout during a training session or meeting.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.
