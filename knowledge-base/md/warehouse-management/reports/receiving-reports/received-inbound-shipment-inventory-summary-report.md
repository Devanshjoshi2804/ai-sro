# Received Inbound Shipment Inventory Summary report

This report displays inbound shipments, defined in your warehouse, that match the parameters you defined. The items that displays on the inbound shipment are grouped by individual planned inbound orders.

The report includes the following details:

-   Client
-   Transport equipment
-   Carrier
-   Inbound shipment ID
-   Inbound shipment location
-   Inbound shipment status
-   Planned inbound order
-   Inbound order
-   Supplier
-   Item
-   Item client
-   Lot
-   Revision level
-   Origin code
-   Receive status
-   Catch quantity
-   Over, short, and damaged (OSD) type
-   Total expected, identified, received, and damaged quantities
