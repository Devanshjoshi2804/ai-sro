# Inventory Activity Summary report

This report displays a summary of the activities associated with specific item or supplier for a specific date range.

The report includes the following details:

-   From and to transaction date
-   Item client
-   Item
-   Supplier
-   Client
-   Receive quantity
-   Shipped quantity
-   Adjusted quantity
-   Work order received quantity
-   Work order consumed quantity
-   Net quantity
-   Transaction date
-   Quantity totals
