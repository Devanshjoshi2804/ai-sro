# Cycle Count Item Summary (for Dates) report

This report displays the locations and items that were counted and adjusted during the range of dates and for the count type that you specify. The report displays count information for counts that have been processed as complete.

The report includes the following details:

-   Item client
-   Beginning and ending count dates during which the counts occurred
-   Item
-   Number of locations counted
-   Number of locations adjusted
-   Percentage of locations adjusted
-   Item value and currency before count
-   Item value and currency after count
-   Net adjusted item value and currency
-   Absolute adjusted value and currency
