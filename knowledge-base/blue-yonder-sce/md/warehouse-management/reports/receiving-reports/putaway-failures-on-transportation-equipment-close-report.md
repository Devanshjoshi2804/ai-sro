# Putaway Failures on Transportation Equipment Close report

This report displays the LPNs for which the application failed to create directed work when configured to do so. The report is only available if the application is configured to create directed putaway work automatically (and fails to do so) after an RF operator closes transport equipment. The application may fail to create directed work, for example, if a suitable storage location could not be found for the inventory.

You can limit the information that displays by entering a transport equipment ID.

The report includes the following details:

-   Transport equipment number
-   Yard location (of the transport equipment)
-   LPN
-   Location (of the LPN)
-   Item
-   Item client
-   Planned inbound order
-   Planned inbound order line
-   Unit quantity
-   Inventory status
