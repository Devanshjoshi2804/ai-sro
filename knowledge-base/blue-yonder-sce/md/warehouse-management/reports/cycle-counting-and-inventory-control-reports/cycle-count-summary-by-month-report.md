# Cycle Count Summary (by Month) report

This report displays the locations, grouped by month, that were counted and adjusted by month since the beginning count that you specify. The report displays count information for counts that have been processed as complete.

The report includes the following details:

-   Item client
-   Count month and year
-   Number of locations counted
-   Number of locations adjusted
-   Percentage of locations adjusted
-   Item value and currency before count
-   Item value and currency after count
-   Net adjusted value and currency
-   Absolute adjusted value and currency
