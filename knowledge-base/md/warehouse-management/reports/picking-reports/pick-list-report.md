# Pick List report

This report displays all of the picks that have been grouped together into work assignments.

This report includes the following details:

-   Client
-   List ID (barcode)
-   Handling unit type
-   Total picks
-   Total items
-   Total cases
-   Total cube
-   Total weight

For each item on the list, the report includes the following details:

-   Work task
-   Source location
-   Slot number
-   Item
-   Item client
-   Inventory status
-   Lot
-   Origin code
-   Revision level
-   Supplier
-   Pick quantity
-   Picking UOM
-   Footprint code details
-   Picked, applied, and remaining quantities (by UOM)
