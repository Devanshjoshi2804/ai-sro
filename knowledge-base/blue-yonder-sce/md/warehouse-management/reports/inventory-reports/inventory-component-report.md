# Inventory Component report

This report displays the location and inventory of a specified component item. The quantities shown only represent inventory within the warehouse. The report also displays the location of the kit in which the specified component item displays (based on the parameters you selected). If no component item is specified, the report lists the location of all component items and kits contained in your facility.

The report includes the following details:

-   Item client
-   Storage location
-   Lot
-   Revision level
-   Supplier
-   Origin code
-   Inventory status
-   Catch unit type
-   Catch quantity
-   Total quantity
-   Hold flag
-   Item
-   Building
-   Area
