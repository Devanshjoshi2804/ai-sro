# Received Inbound Shipment Detail report

This report displays a detailed list of all the LPNs of inventory received against an inbound shipment. You can limit the information that displays by specifying parameter values such as inbound shipment ID or supplier from which the inventory was received.

The report includes the following details:

-   Warehouse
-   Item client
-   Transport equipment
-   Carrier
-   Inbound shipment ID
-   Inbound shipment status
-   Inbound order
-   Supplier
-   Planned inbound order
-   Inbound shipment location
-   Storage location
-   LPN
-   Case ID
-   Piece identifier
-   Unit quantity
-   Item
