# Received Inbound Shipment Inventory report

This report displays all of the LPNs of inventory that have been received from an inbound shipment that you specify, as well as the locations where that inventory exists.

This report includes the following details:

-   Warehouse
-   Item client
-   Item
-   Storage location
-   LPN
-   Case identifier
-   Receive quantity
-   Inbound shipment
-   Transport equipment
-   Carrier
