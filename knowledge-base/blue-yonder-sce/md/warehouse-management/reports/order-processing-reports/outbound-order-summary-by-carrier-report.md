# Outbound Order Summary by Carrier report

This report displays items expected to ship from your warehouse, grouped by carrier. You can limit the report to a specific carrier.

The report includes the following details:

-   Item client
-   Carrier code and name
-   Load
-   Item
-   Gross weight (in pounds)
-   Remaining quantity
-   In process quantity
-   Staged quantity
-   Expected ship date
-   Total quantities
