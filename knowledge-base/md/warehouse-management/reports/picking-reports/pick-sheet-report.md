# Pick Sheet report

This report displays pick information according to the selection criteria that you provide. You can limit the report by any of the following attributes:

-   Source area
-   Source work zone
-   Source location
-   Destination area
-   Ship To work zone
-   Destination location
-   Shipment
-   Outbound order
-   Client
-   Work task
-   Schedule batch number
-   Ship-to customer
-   Work order number
-   Work order revision
-   Comment
-   Item
-   Item client
-   Label batch
-   Label batch

The report includes the following details:

-   Client
-   Comment
-   User
-   Work task (bar coded)
-   Source location (bar coded)
-   Destination location (bar coded)
-   Item
-   Item client
-   LPN
-   Pick quantity
-   Footprint code details
-   Pick quantity
-   Applied quantity
-   Remaining quantity
-   Lot
-   Revision level
-   Origin code
-   Rule name
