# Goal Time Breakdown report

This report provides a detailed side-by-side view of the assignment audit information for a control set and associated variable set.

**IMPORTANT**: This report is functional only when performing simulations and can only be generated from a model instance.

After you select the report, you can provide a description of the report and enter selection criteria to limit the output of the report.

## Goal Time Breakdown report fields

 
| Field | Description |
| --- | --- |
| Variable Set ID | Unique identifier for the variable set. A variable set is a copy of a control set's historical assignments used to reflect the impact of changes (such as to the warehouse map or to standards) on the assignment audit information (such as goal time, KVI, and travel time). |
| Warehouse | Unique identifier associated with the warehouse. In a multi-warehouse environment, you can select the warehouse for which you are authorized. |
| Variable Set | Copy of a control set's historical assignments used to reflect the impact of changes (such as to the warehouse map or standards) on the assignment audit information (such as goal time, KVI, and travel time). |
| Show Graph | Indicates whether a bar graph containing the report information is also included in the generated report. |
| Subtitle | Additional descriptive information that will be displayed below the title in the generated report. |
