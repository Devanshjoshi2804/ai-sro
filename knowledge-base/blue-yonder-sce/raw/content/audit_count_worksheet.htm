Audit Count worksheet

This report displays all of the LPNs in an audit location as well as the attributes of the inventory on those LPNs. The report is used in to reconcile the quantity of inventory that the application assumes is in the audit location with the actual physical inventory in the location. You can limit the information that displays by entering a specific count group, count batch, count wave, or storage location.

The audit count work sheet includes the following count details:

  • Count batch
  • Count group
  • Count wave
  • Count mode
  • Request type
  • Comments
  • Storage location
  • Audit signature
  • Item and description
  • Item client
  • Count user
  • Unit quantity
  • Count quantity

In addition, the audit count work sheet includes an area that displays the following inventory information:

  • Warehouse
  • LPN
  • Item and description
  • Item client
  • Inventory status
  • Lot
  • Revision level
  • Origin code
  • On hold
  • Catch unit type
  • Units per case
  • Units per pack
  • Unit quantity
  • Catch quantity
  • Unit cost and currency code
  • Cost variance and currency code = (count quantity - unit quantity) x unit cost
