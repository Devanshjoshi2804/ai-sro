# Transport Equipment Type

A transport equipment type configuration identifies characteristics that are shared by individual pieces of transport equipment. For example, you can create a type for flatbed trailers, one for 48 ft. rear load trailers, and another for equipment that has a liftgate.

In addition to a name and description, each transport equipment type configuration specifies the dock access groups for the type of equipment. A dock access group is also assigned to dock door locations, and it is used to sort and display the dock doors that are available for specific types of transport equipment during check in and when moving equipment to a door location. See [Dock Access Groups](../../warehouse/locations/dock-access-groups.md).

## Add or modify a transport equipment type

1.  Select **Configuration > Equipment > Equipment > Transport Equipment Type**.
2.  Perform one of the following tasks:
    -   To add a new transport equipment type, click **Add**.
    -   To modify a transport equipment type, in the grid, click the transport equipment.
3.  In the **Equipment**, **Description**, and **Short Description** fields, enter the information.
4.  To assign dock access groups to the transport equipment type:
    
    **Note**: If you assign a dock access group, locations with a matching dock access group are displayed before mismatched door location. See [Dock Access Groups](../../warehouse/locations/dock-access-groups.md).
    
    1.  Click **Dock Access Groups**.
    2.  In the **Available** column, select the check box next to the dock access groups that apply.
    3.  Click **Apply**.
5.  Click **Save**.

## Delete a transport equipment type

1.  Select **Configuration > Equipment > Equipment > Transport Equipment Type**.
2.  In the grid, select the check box next to the type to delete.
3.  Click **Delete**. A confirmation message is displayed.
4.  Click **OK**.
