# Work Order Movement report

This report displays the work orders that have been moved from one production line to another production line. You can limit the information that displays by work order, client, work order revision, work order type, and warehouse.

The report includes the following details:

-   Warehouse
-   Work order number
-   Work order revision
-   Client
-   Work order type
-   Item
-   Item client
-   Old production line
-   New production line
-   Disassembly (indicates a disassembly work order)
-   Old and new production station
-   Revision level origin code
-   Total delivered quantity
-   BOM quantity
-   Total remaining quantity
