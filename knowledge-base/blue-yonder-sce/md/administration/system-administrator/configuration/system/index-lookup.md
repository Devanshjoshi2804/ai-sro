# Index Lookup

The Index Lookup page provides index information defined for application server instance database tables. The information displayed for a selected database table includes the index name and the associated column names and column positions. If a selected database table does not have an index defined, the **INDEXES** grid is blank.

## View an index defined for a database table

1.  Select **System Administrator > Configuration > ** **System > Index Lookup**.
2.  In the grid, select a table. The index information is displayed in the **INDEXES** grid.
