# Audit Trail report

This report provides concise details on every aspect of goal time calculation, including key volume indicator (KVI), discrete travel, and handling calculations. In addition, you can view the variance (level of precision) at which an assignment is accomplished.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.

## Audit Trail report fields

 
| Field | Description |
| --- | --- |
| From Date | Starting date for a specific date range. |
| To Date | Ending date for a specific date range. |
| Date Range | Date range for the information that is included in the report. You can select a date that is relative to today's date (such as Yesterday, Last Week, or Last Year) or you can enter a custom date range. |
| User ID | Unique identifier of the user. A user is an individual who will be using the application, either with direct access or through an internet connection. |
| Assignment # | Unique identifier of the assignment. An assignment represents the basic unit of work that a user performs in your facility. |
| Plan Date | Date on which the assignment is expected to be performed. |
| Indicator | Application-generated letter used to designate a split or merged assignment. |
| Observed | Indicates whether to display assignments that have been observed. |
| Subtitle | Additional descriptive information that will be displayed below the title in the generated report. |
