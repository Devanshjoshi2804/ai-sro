# Cycle Count Summary (for Dates) report

This report displays the locations that were counted and adjusted for a range of dates and count type that you specify. The report displays count information for counts that have been processed as complete.

The report includes the following details:

-   Item client
-   Beginning and ending count dates on which the counts occurred
-   Number of locations counted
-   Number of locations adjusted
-   Percentage of locations adjusted
-   Item value and currency before count
-   Item value and currency after count
-   Net adjusted value and currency
-   Absolute adjusted value and currency
