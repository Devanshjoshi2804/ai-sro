# Holds - Configuration

A hold is a warehouse-specific attribute that is applied to inventory without changing the inventory status. It can be defined, maintained, and applied manually by a user or automatically through inbound integration transactions.

When you configure holds, you define active holds on inventory, groups of similar holds for display and reporting purposes, and codes that explain the reason for a hold's application or removal.
