# Adjustment Reasons

An inventory adjustment reason is a code that explains why an inventory adjustment was made by an operator.

## Add or modify an adjustment reason

1.  Select **Configuration > Inventory > Inventory Adjustments > Adjustment Reasons**.
2.  Perform one of the following tasks:
    -   To add a new adjustment reason, click **Add**.
    -   To modify an adjustment reason, in the grid, click the reason.
    -   To copy an adjustment reason, in the grid, select the check box next to the reason, and then click **Copy**.
3.  Perform one of the following tasks:
    -   In the **Adjustment Reason** field, enter a reason code.
    -   To have the application supply a reason code, select the **System Generated** check box.
4.  In the **Adjustment Reason Description** field, enter a description of the reason.
5.  To assign the adjustment reason to clients:
    1.  Click **Clients**. The Clients page is displayed.
    2.  In the **Available** column, select the check box next to the clients that use the adjustment reason.
    3.  Click **Apply**.
6.  Click **Save**.
