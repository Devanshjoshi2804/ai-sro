# Application overview

Event Management is a web-based solution that helps you proactively manage your logistics operations by notifying you, through various methods, about critical system and operational actions at the time that they occur.

The following examples describe notifications that can be configured when Event Management is integrated with Warehouse Management:

-   An account representative can receive an email message, an instant message, or both whenever a critical shipment is cancelled so that the customer can be notified immediately.
-   Warehouse managers can be notified that a conveyor is down as soon as it goes offline so that immediate action can be taken to avoid lost time and order delays.
-   Floor supervisors can be notified when a large order download is received so that additional resources can be allocated to complete the work.
-   System administrators can be notified that a tablespace within a database has exceeded its threshold.

## Integrations

Event Management supports integration with the following Blue Yonder applications:

-   Integrator (Supply Chain Execution)
-   Warehouse Labor Management
-   Warehouse Management

Event Management can also be installed as a standalone application that works with third-party systems to gather, store, and provide event and alert functionality.
