# Returns

The Returns functionality provides visibility into return orders and the ability to manage their intake. The returns process consists of either an expected or unexpected return arriving at the warehouse with a downloaded or generated return order, an operator identifying its information in the application, and then completing the return processing by closing the order and placing inventory on a pallet to be delivered to its next destination.

For more information and setup tasks, see the [Returns](configuration/inbound/returns.md) configurations.
