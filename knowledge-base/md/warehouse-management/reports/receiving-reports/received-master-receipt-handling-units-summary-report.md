# Received Master Receipt Handling Units Summary report

This report displays a detailed list of all the handling units that are expected, identified, and received.

The report includes the following details:

-   Client
-   Master receipt ID
-   Inbound shipment status
-   Order ID
-   Planned inbound order
-   Supplier
-   Warehouse
-   Carrier
-   Transport equipment
-   Expected handling unit quantity
-   Identified handling unit quantity
-   Received handling unit quantity
-   Handling unit type
-   Handling unit ID
-   Handling unit status
-   Handling unit serialized
-   Load
-   Inbound order
-   Inventory identifier
-   Handling unit quantity
-   Handling unit identifier
