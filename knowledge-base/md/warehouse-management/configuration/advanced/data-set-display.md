# Data Set Display

You use Data Set Display to view a list of the shared application library (SAL) data sets that are loaded into a Supply Chain Execution (SCE) application installation. Typically, the Data Set Display page is used only for troubleshooting purposes.

A data set is a collection of data installed during installation to populate the database in order to support a particular function or integration. For example, depending on your application installation, the following types of data sets may be displayed:

-   **SAL Base Data**: Required to support shared application library (SAL) application windows.
-   **SAL 3PL Data**: Required to support third-party logistics in Warehouse Management.
-   **SAL USA Geo Data**: Required to validate U.S. addresses, and calculate distances and time zones.
-   **SAL Canada Geo Data**: Required to validate Canadian addresses, and calculate distances and time zones.
-   **SAL <**Application Name** > Data**: Required to support integration with an application, such as Event Management, Warehouse Labor Management, or Warehouse Management.

## View data sets

1.  Select **Configuration > Advanced > Data Set Display**.
2.  View information in the following fields:
    

 
| Field | Description |
| --- | --- |
| **Data Set Description** | Meaningful description of the data set. |
| **Data Set Directory** | Location of the data set on the instance server. |
| **Data Set Name** | Named collection of data that was loaded into the application instance during installation. |
| **Data Set Sequence** | Sequence of the data set. |
