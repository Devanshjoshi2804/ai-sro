# Table Definition

The Table Definition page displays the list of tables in the application server instance database, and detailed column information for a selected table.

**Note**: Portal server database table information is not displayed on the Table Definition page.

## View a table definition

1.  Select **System Administrator > Configuration > ** **System > Table Definition**.
2.  In the tables grid, select a table.
3.  View the information in the [Columns fields](#Columns_fields).

## Columns fields

 
| Field | Description |
| --- | --- |
| Table Name | Name of the database table. |
| Column Name | Unique identifier for the column. |
| Description | Text that further describes the column name. |
| MOCA Data Type | Type of data that is supported in the column.<br>-   • **D**: DateTime
<br>-   • **F**: Float
<br>-   • **I**: Integer
<br>-   • **O**: Boolean
<br>-   • **S**: String |
| Length | Maximum number of characters allowed for a valid data entry in the column. |
| Null Allowed | If true, then a blank value is accepted in the column.<br > If false, then a value is required in the column. |
| Primary Key | If true, then the column is a primary key in the database table.<br > If false, then the column is not a primary key in the database table. |
| Identity Column | If true, then this column is an identity column in the database table.<br > If false, then this column is not an identity column in the database table. |
| Column Comment | Text that further describes the column. |
