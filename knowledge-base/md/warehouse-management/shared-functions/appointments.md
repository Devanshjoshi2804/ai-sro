# Appointments

The Appointments page is accessible from the following modules: **Receiving**, **Shipping**, or **Yard**.

You use the Appointments page to create new appointments and view and manage existing appointments. All existing appointments are displayed in a timeline grid from which you can search and scroll to find an appointment by a specific type, date, time, and duration.

This page consists of the following elements:

-   **Dock Sets, Doors, All**: Determines whether only the dock sets are displayed in the timeline grid, only the dock doors, or all of the dock sets and doors.
-   **Search fields**:
    -   **Transport equipment type drop-down list**: Determines the type of transport equipment that is displayed in the search results, or the equipment type for which a new appointment is created. You can select one of the following transport equipment types: Receiving, Shipping, or Storage.
    -   **Date**: Date on which the appointment is or will be scheduled.
    -   **Time**: Time of day at which the appointment is or will be scheduled. This drop-down list is incremented in 15 minute intervals.
    -   **Duration**: The duration of the appointment in hours and minutes.
-   **Timeline**: Allows you to view the appointment time, duration, and number of appointments for each hour of the day. Additionally, you can navigate the timeline forward in time by clicking ![Later time](../../../images/resources/images/image430109.png), backward by clicking ![Earlier time](../../../images/resources/images/image430108.png), and to the present date and time by clicking ![Present time](../../../images/resources/images/image430893.png).
-   **Timeline grid**: Displays the schedule for the dock sets and doors for the time displayed in the timeline. Existing receiving appointment bars are displayed in blue; shipping appointment bars are green; storage appointment bars are yellow. You can click and drag in an available time slot to create a new appointment for a dock set or door, or click an existing appointment bar to edit appointment details. See [Add or modify an appointment](appointments/procedures-for-appointments.md).
