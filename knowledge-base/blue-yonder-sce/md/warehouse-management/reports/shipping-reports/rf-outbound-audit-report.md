# RF Outbound Audit report

This report includes detailed information for completed outbound audits. An outbound audit is a process that is performed by an RF operator to validate that the inventory picked for a shipment matches the expected inventory. In addition to listing the inventory attributes that were confirmed by the operator during the audit, this report also includes the following information:

-   Identifier for the inventory that was audited
-   The start and end date and time of the audit
-   Warehouse in which the audit was performed
-   Location in which the inventory was audited
-   Identifier for the shipment to which the audited inventory belongs
