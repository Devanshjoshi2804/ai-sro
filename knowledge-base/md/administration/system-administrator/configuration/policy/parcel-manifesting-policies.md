# Parcel Manifesting policies

The Parcel Manifesting (PARCEL-MANIFEST) policies are used to control parcel manifesting attributes and processes. The following table lists the parcel manifesting policies, and the pages in the Warehouse Management web client where the policies can be configured. For information on parcel processing configuration, see [Parcel - Configuration](../../../../warehouse-management/configuration/outbound/shipping/parcel.md).

 
| Policy | Web client |
| --- | --- |
| PARCEL-MANIFEST/CONFIGURATION/PCL-PRINT-PAPERWORK<br > **Note**: Reserved for future use. | Parcel page:<br > **Parcel Shipment Paperwork** field |
| PARCEL-MANIFEST/CONFIGURATION/DELIVERY-DATES-FOR-MANIFEST | Parcel page:<br > **Use Delivery Date** field |
| PARCEL-MANIFEST/CONFIGURATION/VALD-PACKAGE-MANFST-BEFORE-STAGING | Parcel page:<br > **Manifest Before Staging** field |
| PARCEL-MANIFEST/CONFIGURATION/ONLY-RATE-ON-LAST-PKG<br > **Note**: Reserved for future use. | Parcel page:<br > **Multi-Package Shipments** field |
| PARCEL-MANIFEST/CONFIGURATION/PACKAGE-WEIGHT-MULTIPLIER<br > **Note**: Reserved for future use. | — |
| PARCEL-MANIFEST/DEFAULT/COUNTRY-CODE | Parcel page:<br > **Default Country** field |
| PARCEL-MANIFEST/DEFAULT/REPORT-PREFIX<br > **Note**: Reserved for future use. | — |
| PARCEL-MANIFEST/INSTALLED/FASCOR | General Integration page:<br > **Parcel** field |
| PARCEL-MANIFEST/MINIMUM-DIMENSIONS/FEDEX<br > **Note**: Reserved for future use. | — |
| PARCEL-MANIFEST/REMOTE/SERVICE | Parcel page: <br > **Parcel Service** field |
| PARCEL-MANIFEST/THREADING/ENABLED | Parcel page:<br > **Allow Pre Manifesting** field |
| PARCEL-MANIFEST/THREADING/THREAD-COUNT<br > **Note**: Reserved for future use. | — |
| PARCEL-MANIFEST/TRACE/MANIFEST-PACKAGE<br > **Note**: Reserved for future use. | — |
| PARCEL-MANIFEST/TRACE/RATE-SHOP<br > **Note**: Reserved for future use. | — |
