# Inventory Summary report

This report displays summarized inventory information, grouped by building and zone. You can limit the information that displays by specifying a building, area, storage location, item, item client, supplier, inventory status, units per pack, units per case, and size.

The report includes the following details:

-   Item client
-   Building
-   Area
-   Storage location
-   Item and item description
-   Supplier
-   Inventory status
-   Unit quantity
-   Pending quantity
-   Committed quantity
-   Available quantity (Unit Quantity - Committed Quantity)
