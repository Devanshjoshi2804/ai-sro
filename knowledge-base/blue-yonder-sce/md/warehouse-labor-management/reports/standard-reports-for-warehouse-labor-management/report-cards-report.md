# Report Cards report

This report is used to view the calculated report card scores and grades for users based on defined report cards for your facility. There are two variations of the Report Cards report. Your user configuration determines which of the following reports you can generate:

-   **Report Cards**: Supervisors (or other authorized user) can view the report score and grade information for any user in the facility.
-   **Report Card - User**: Users can log in to view their report card score and grade information. Users can view only their own report card score and grade.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to limit the output of the report.

## Report Cards report fields

 
| Field | Description |
| --- | --- |
| Warehouse | Unique identifier associated with the warehouse. In a multi-warehouse environment, you can select the warehouse for which you are authorized. |
| Report Card | Unique identifier for the report card. A report card is part of a customized incentive or disciplinary program within your facility. |
| User ID | Unique identifier of the user. A user is an individual who will be using the application, either with direct access or through an internet connection. |
| Date Range | Date range for the information that is included in the report. You can select a date that is relative to today's date (such as Yesterday, Last Week, or Last Year) or you can enter a custom date range. |
| From Date | Starting date for a specific date range. |
| To Date | Ending date for a specific date range. |
| Supervisor | Person to whom a user reports. A supervisor manages and oversees a user's work. You can also use the supervisor's ID for easy user selection in reports, assignments, performance statistics, report cards, and payroll information. |
| User Group | Optional category into which users can be grouped for easy selection in reports, assignments, performance statistics, report cards, and payroll information. |
| Work Team | Optional category into which users can be grouped for easy selection in reports, assignments, performance statistics, report cards, and payroll information. |
| Report Group | Optional category into which users can be grouped for easy selection in reports, report cards, and payroll information. |
| Detail by Job Code | Indicates whether job code details are included in the generated report. Not available on the Report Card - User Report page. |
