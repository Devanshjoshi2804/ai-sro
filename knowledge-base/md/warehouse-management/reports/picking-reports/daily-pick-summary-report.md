# Daily Pick Summary report

This report displays schedule batches and the quantity required to be picked for each schedule batch. You can limit the report by a date range.

The report includes the following details:

-   Date range in which the schedule batch was added
-   Schedule batch number
-   Pick quantity
-   Applied quantity
-   Percent complete
