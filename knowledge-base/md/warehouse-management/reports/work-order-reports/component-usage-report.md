# Component Usage report

This report displays all work orders for which components have been tracked and consumed, and the attributes and quantity of the components that have been consumed during the processing of each work order. You access a component usage report by entering the work order number, the work order revision level, and the client. All current and archived work orders are accessible.

The report includes the following details:

-   Warehouse
-   Item
-   Item client
-   Lot
-   Revision level
-   Supplier
-   Origin code
-   Total quantity
-   Work order number
-   Work order revision
-   Client
