# Cycle Count (Deferred) report

This report displays the pickable locations that contain deferred counts. You can limit the information that displays by entering an area, location, item, and item client before you generate the report.

The report includes the following details:

-   Warehouse
-   Item client
-   Area
-   Storage location
-   Item
-   Committed quantity
-   Pending quantity
-   Date added
