# Work Order Setup report

This report displays detailed information on the setup of the components contained in the work order. You can limit the information that displays by entering a work order number, client, or the work order revision.

The report includes the following details about the line items:

-   Order line
-   Item
-   Item client
-   Inventory status
-   Unit quantity
-   Lot
-   Revision level
-   Origin code
-   Work order number
-   Client
-   Work order revision
-   Work order type
-   Disassembly
