# Consolidated User report

This report is used to view up to six standard reports for a user or for multiple users. When you run this report for more than one user, the resulting information is appended one after another. You can view the following reports:

-   Metric Data report
-   Observation Detail report
-   Quality report
-   Report Cards report
-   Summary report
-   User Milestone report

You can specify the date range for which information is collected and enter selection criteria to limit the output of the report.

## Consolidated User report fields

 
| Field | Description |
| --- | --- |
| From Date | Starting date for a specific date range. |
| To Date | Ending date for a specific date range. |
| Date Range | Date range for the information that is included in the report. You can select a date that is relative to today's date (such as Yesterday, Last Week, or Last Year) or you can enter a custom date range. |
| User ID | Unique identifier of the user. A user is an individual who will be using the application, either with direct access or through an internet connection. |
| Warehouse | Unique identifier associated with the warehouse. In a multi-warehouse environment, you can select the warehouse for which you are authorized. |
| Group by Period | Grouping level by which the information is organized. You can select Fiscal Month, Fiscal Week, Month, Report Date, and Week. |
| Show Report Card Report | Indicates whether the Report Cards Report information is included in the generated report. |
| Report Card | Unique identifier for the report card. A report card is part of a customized incentive or disciplinary program within your facility. |
| Show Summary Report | Indicates whether the Summary Report information is included in the generated report. |
| Group By (1–3) | Grouping level by which the information is organized (for example, by supervisor or user). You can have up to three levels of grouping. |
| Show Quality Error | Indicates whether quality error information is included in the generated report. A quality error is used to identify when the overall inventory status of an item is no longer considered acceptable. |
| Show Clock Punch | Indicates whether clock punch information is included in the generated report. A clock punch is a record marking (or indicating) a starting or ending date and time for a user. Only available if you are using Time and Incentives functionality. |
| Show Blended Cost | Indicates whether blended cost information is included in the generated report. Blended cost is an estimated rate for the user. |
| Show Expected Performance | Indicates whether expected performance information is included in the generated report. Expected performance is a performance value that a user is held to based on actual performance. Only available if False is selected in the **Show Payroll Cost** field. |
| Show Payroll Cost | Indicates whether payroll cost information is included in the generated report. Payroll cost is the actual pay rate for the user. |
| Show Utilization % | Indicates whether utilization percentage is included in the generated report. Utilization % is the percentage of paid time a user spends on direct work (value-added activity). |
| Show Quality Report | Indicates whether the Quality Report information is included in the generated report. |
| Show Observation Detail Report | Indicates whether the Observation Detail Report information is included in the generated report. |
| Show Metric Data Report | Indicates whether the Metric Data Report information is included in the generated report. |
| Milestone Type | Significant operation-specific event in a person’s employment, such as completion of a training course, a certification requirement, a coaching session, an observation, or a reprimand, which could have an impact on a user's performance against metrics. |
| Metric | Unique identifier for the metric. A metric is business data that is accumulated over time and used as a standard of measurement that may be analyzed for trends or alert statuses. Only displayed if True is selected in the **Show Metric Data Report** field. |
| Show User Milestone Report | Indicates whether the User Milestone Report information is included in the generated report. |
