# WCS Inventory Snapshot

You use the WCS Inventory Snapshot page to view and compare inventory data in a warehouse control system (WCS) to inventory data in Warehouse Management. Inventory snapshots from the WCS are assumed to be the current state of the WCS. Additional configuration is required in the WCS to handle and process inventory snapshots.

You can also configure the attributes expected from the WCS for comparison. See [Inventory reconciliation settings for WCS integration](../configuration/integration/warehouse-control-system-integration/systems-and-settings-for-wcs-integration.md).

## View the WCS inventory snapshot

1.  Select **Inventory > WCS Inventory Snapshot**.
    
2.  Enter search criteria to display snapshot information.
    
3.  View information in the WCS Inventory Snapshot fields.
