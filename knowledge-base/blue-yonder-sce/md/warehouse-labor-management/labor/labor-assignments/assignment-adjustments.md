# Assignment adjustments

An adjustment is the amount of unmeasured time, such as for a break or meeting, that is deducted from the assignment's actual time to provide a more accurate user performance value. You can make adjustments directly to a particular assignment, or when the specific assignment information is not known, you can make adjustments to the user, and the application will then automatically apply the adjustment to the appropriate assignment. For example, if a user attended a meeting from 9:00 A.M. until 10:00 A.M., you can insert an adjustment for that time frame, and it will be applied to the user's assignment that had an Active status at the start time of the adjustment.

## Add or modify an assignment adjustment

When you add or modify an assignment adjustment, the actual time recorded for the assignment is reduced by the adjustment time.

1.  Select **Labor > Labor Assignments**.
2.  On the Search pane, enter criteria for the assignment, and then click **Search**.
3.  In the Assignments grid, select the assignment for which to add an adjustment.
4.  On the Assignment details pane, select the **Adjustments** tab.
5.  Perform one of the following tasks:
    -   To add an adjustment, from the **Actions** drop-down list, select **Add Adjustment**.
    -   To modify an adjustment, select the adjustment, and then from the **Actions** drop-down list, select **Modify Adjustment**. 
6.  Enter information in the following fields:
    
     
    | Field | Description |
    | --- | --- |
    | Job Code | Unique identifier for a job code. A job code represents a standard for a task being performed in your facility, and it is the basic component for an assignment. You cannot select an activity card job code for a new assignment. |
    | Adj. Minutes | Number of minutes to be adjusted into the assignment for the unmeasured task. |
    | Adj. Seconds | Number of seconds to be adjusted into the assignment for the unmeasured task. |
    
7.  Click **Add Adjustment** or **Modify Adjustment**. A confirmation message is displayed.

## Approve or reject an assignment adjustment

1.  Select **Labor > Labor Assignments**.
2.  On the Search pane, enter criteria for the assignment, and then click **Search**.
3.  In the Assignments grid, select the assignment for which to approve or reject an adjustment.
4.  On the Assignment details pane, select the **Adjustments** tab.
5.  In the grid, select the adjustment to approve or reject.
6.  Perform one of the following tasks:
    -   To approve the adjustment, from the **Actions** drop-down list, select **Approve Adjustment**, and then click **Yes**.
    -   To reject the adjustment, from the **Actions** drop-down list, select **Reject Adjustment**, enter a reason for the rejection, and then click **Reject**. A confirmation message is displayed.

## Delete an assignment adjustment

1.  Select **Labor > Labor Assignments**.
2.  On the Search pane, enter criteria for the assignment, and then click **Search**.
3.  In the Assignments grid, select the assignment for which to delete an adjustment.
4.  On the Assignment detail pane, select the **Adjustments** tab.
5.  Select the adjustment to delete, and then from the **Actions** drop-down list, select **Delete Adjustment**. A confirmation message is displayed.
6.  Click **Yes**.
