# Master Handling Summary report

This report displays the summary of a completed work assignment that was picked to a master handling unit. A master handling unit is a handling unit that contains slots to which inventory is picked for sequenced orders. This report is typically configured to be printed (as a label, report, or both) upon successful completion of a work assignment for sequenced orders.

You can limit the information on the report by List ID (Work Assignment).

This report includes the following details:

-   Header information
-   Work assignment
-   Item family sequence
-   Handling unit type
-   Closed time
-   Pick to ID (LPN)
-   Detail information
-   Slot
-   Item
-   Planned order sequence
-   Ordered quantity
-   Picked quantity
-   Total ordered quantity
-   Total picked quantity
