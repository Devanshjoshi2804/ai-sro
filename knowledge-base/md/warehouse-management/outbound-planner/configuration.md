# Configuration - Outbound Planner

The Configuration page in the Outbound Planner module provides access to the configurations relevant for outbound processing. You can modify configurations as necessary to accommodate the outbound process for your warehouse. After you access the Configuration page (select **Outbound Planner > Configuration**), see the following topics that support the available outbound configurations:

**Note**: The configurations available in the Outbound Planner module may differ from those that are available in the Configuration module.

-   [Order Processing](../configuration/outbound/order-processing.md)
-   [Allocation](../configuration/outbound/allocation.md)
-   [Picking](../configuration/outbound/picking.md)
-   [Movement](../configuration/inventory/movement.md)
-   [Packing](../configuration/outbound/packing.md)
-   [RF Outbound Audit Settings](../configuration/outbound/rf-outbound-audit-settings.md)
-   [Distribution](../configuration/outbound/distribution.md)
-   [Shipping](../configuration/outbound/shipping.md)
