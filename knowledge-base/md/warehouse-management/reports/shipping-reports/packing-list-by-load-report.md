# Packing List (by Load) report

This report displays the picked inventory carton information for each order on a load. The report includes the following details:

-   Client
-   Warehouse
-   Order
-   Customer inbound order number
-   Shipment
-   Ship-to customer
-   Bill-to customer
-   Notes
-   Item family
-   Item
-   UPC
-   Serial number
-   Unit quantity
-   Total pieces
