# Packing List report

The following report displays the picked inventory carton information for an order number and shipment ID combination. For example, if order ORD1 exists on shipment SHP1, then one packing list will be printed. However, if ORD1 exists on both shipments SHP1 and SHP2, then two packing lists (one for each shipment) will be produced, displaying carton information for each respective shipment.
