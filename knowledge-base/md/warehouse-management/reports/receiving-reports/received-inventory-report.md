# Received Inventory report

The following report provides visibility into potential receiving discrepancies by comparing expected planned inbound order information with actual received information for a particular inbound shipment.

The report includes the following details about the inbound shipment:

-   Inbound shipment identifier
-   Inbound shipment location
-   Inbound shipment status
-   Client
-   User names of those involved in the receiving process
-   Planned inbound order
-   Supplier
-   Planned inbound order type
-   Inbound order
-   Transport equipment
-   Carrier
-   Seal number
-   Actual check-in date
-   Expected check-in date

The report includes the following details for planned inbound order lines on the inbound shipment:

-   Item and item description
-   Item client
-   Lot
-   Unit of measure
-   Revision level
-   Origin code
-   Receive status
-   Quantity
-   Expected
-   Identified
-   Received
-   Damaged
-   Discrepancy
-   Catch quantity
-   Expected
-   Identified
-   Received
-   Damaged
-   OSD Type
-   Total quantity
    -   Expected
    -   Identified
    -   Received
    -   Damaged

The report includes the following details for the loads of inventory that have been received from the inbound shipment:

-   LPN
-   Storage location
-   Item
-   Revision level
-   Origin code
-   Lot
-   Inventory status
-   Unit quantity
