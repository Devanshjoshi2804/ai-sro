# Item Footprint Affected Outstanding Work report

This report displays information about outstanding pick work, outstanding carton pick work, affected inventory locations, pending putaways, pallet stack height locations, and order plans associated with an item footprint. Item footprints are used to designate the packaging dimensions of items within your facility. You can limit the report by item and footprint.

The report includes the following details:

-   Item
-   Item client
-   Footprint and description
-   LPN
-   Sub-LPN
-   Detail LPN
-   Location
-   Area
-   Warehouse
-   Lot
-   Revision level
-   Origin code
-   Supplier
