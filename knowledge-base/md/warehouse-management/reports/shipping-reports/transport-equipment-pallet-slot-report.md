# Transport Equipment Pallet Slot report

This report lists the pallet slots captured for a piece of transport equipment and the inventory assigned to each pallet slot grouped by LPN, transport equipment, carrier, and stop ID. You give this report to a carrier, especially when the transport equipment was loaded out of stop sequence order, so that when unloading a stop, the carrier can locate all of the inventory for the stop in the transport equipment. If the TRLR-PAL-SLOT background warehouse workflow is enabled, then this report prints automatically when you close a piece of transport equipment for which you captured transport equipment pallet slots.

You can also manually print this report when printing paperwork during shipping operations.

This report only contains information for transport equipment that have had pallet slots captured for them and have been closed.

The transport equipment pallet slot information includes the following details:

-   Address name of the stop
-   LPN
-   Pallet slot

You can limit the information that displays on the report or choose specific details that you want to see when you select any or all of the following parameters before you preview this report:

-   Transport equipment
-   Carrier
-   LPN
-   Pallet slot

If no parameters are specified, the report lists all pallet slots and their associated inventory that have been captured for any and all pieces of transport equipment that currently exist in the application.
