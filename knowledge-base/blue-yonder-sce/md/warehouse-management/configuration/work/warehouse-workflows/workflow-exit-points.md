# Workflow Exit Points

A workflow exit point is a point during warehouse processing that can be assigned to a workflow. During processing, when the workflow exit point occurs, the application either prompts the user to perform the workflow or, for a background workflow, executes the workflow without user intervention.

You use the Workflow Exit Points page to view the exit points that are available for each exit point type.

## View workflow exit points

1.  Select **Configuration > Work > Warehouse Workflows > Workflow Exit Points**.
2.  View the information in the following fields:
    
     
    | Field | Description |
    | --- | --- |
    | Exit Point Type | Category that identifies the type of workflow to which the exit point can be assigned. An exit point may be available for use with one or more exit point types. |
    | Exit Point | Point in the warehouse process at which the application executes workflows to which the exit point has been assigned. |
