# Pick Exceptions report

This report displays information about canceled picks. You can limit the report by a date range, work type, shipment, outbound order, work order, work order revision, item, cancel code, user, source location, destination location, lot, revision level, and origin code.

The report includes the following details:

-   Date range
-   Client

For each cancelled pick the report includes the following details:

-   Cancel date
-   Work task and work type
-   Item
-   Item client
-   Cancel code
-   Cancel user
-   Remaining quantity
-   Order
-   Shipment
-   Shipment line
-   Lot
-   Revision level
-   Origin code
-   Work order
-   Work order revision
-   Source location
-   Ship to (destination) location
