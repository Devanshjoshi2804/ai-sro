# User Productivity report

This report displays basic labor productivity information for individual users. The report includes the following details:

-   User ID
-   User first and last names
-   Activity code and description
-   Pallet and case quantities
-   Activity count
-   Total quantity of the employee
-   Total activity of all the employees
