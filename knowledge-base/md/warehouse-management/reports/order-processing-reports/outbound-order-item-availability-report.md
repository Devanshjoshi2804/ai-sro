# Outbound Order Item Availability report

This report displays the order line items of a specified order and all the pickable locations in your facility that contain inventory, grouped by allocation profile, that can be used to satisfy each order line. You can limit the information that displays by entering an outbound order, outbound order line, outbound order sub-line, client, supplier, or date on which the order was entered into the application.

This report includes the following details:

-   Client
-   Order number
-   Date entered
-   Order line
-   Item
-   Item client
-   Order sub-line
-   Ordered quantity
-   Supplier
-   Units per case
-   Rule name and value (allocation rule)
-   Units per pack
-   Lot
-   Inventory status progression (allocation profile)
-   Origin code
-   Revision level
-   For each inventory status, the report displays the following additional details:
    -   Area
    -   Location
    -   On hold
    -   Unit quantity
    -   Committed quantity
    -   Pending quantity
    -   Catch quantity
