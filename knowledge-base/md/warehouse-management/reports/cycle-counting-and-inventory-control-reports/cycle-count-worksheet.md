# Cycle Count worksheet

This report displays all cycle count information from count batches that have been completed, and have been performed in the facility. You can limit information by entering a specific count group.

The report includes the following details:

-   Item client
-   Count wave
-   Count group
-   Count mode
-   Request type
-   Number of counts
-   Count user
-   Comments
-   Storage location
-   Count batch
-   Item
-   Count quantity
