# Configuration - Inventory

The Configuration page in the Inventory module provides access to the configurations relevant for inventory processing. You can modify configurations as necessary to accommodate the process for your warehouse. After you access the Configuration page (select **Inventory > Configuration**), see the following topics that support the available inventory configurations:

**Note**: The configurations available in the Inventory module may differ from those that are available in the Configuration module.
