# Shared functions

Warehouse Management is distributed with a specific set of modules that represent the areas of functionality within a warehouse facility. Each module contains a default set of pages (or tabs) that enable you to effectively perform the tasks associated with the functional area. The pages described in this section are not exclusive to one module; instead, they are shared pages that are distributed across the menus of two or more functional modules.
