# Velocity Type

A velocity type is a slotting attribute that is used as criteria in a slotting plan to select items to be slotted. When you use a velocity type as a slotting attribute, you can define qualifiers such as the pick quantity, UOM, and date range for selecting items to slot using that criteria. See the information on Slotting in the _Supply Chain Execution Help_.

In addition, velocity types are used on the Item Velocity page, which displays the quantities tracked for an item based on item velocity policy settings. See the information on item velocity processing behavior in the _Supply Chain Execution Help_.

A set of predefined velocity types are provided in standard product.

**IMPORTANT**: Velocity types and item velocity policies are available when Slotting is installed and enabled in Warehouse Management.

## Add or modify a velocity type

1.  Select **Configuration > Advanced > Velocity Type**.
2.  Perform one of the following tasks:
    -   To add a new velocity type:
        1.  From the **Actions** drop-down list, select **Add**.
        2.  In the **Velocity Type** field, enter a name for the velocity type.
        3.  In the **Description** field, enter a description for the velocity type.
    -   To modify a velocity type:
        1.  Select the check box next to the velocity type, and then from the **Actions** drop-down list, select **Edit**.
        2.  In the **Description** field, enter a description for the velocity type.
    -   To copy a velocity type:
        1.  Select the check box next to the velocity type, and then from the **Actions** drop-down list, select **Copy**.
        2.  In the **Velocity Type** field, enter a name for the velocity type.
        3.  In the **Description** field, enter a description for the velocity type.
3.  Click **Save**.

## Delete a velocity type

1.  Select **Configuration > Advanced > Velocity Types**.
2.  In the grid, select the check box next to the velocity type to delete.
3.  From the **Actions** drop-down list, select **Delete**. A confirmation message is displayed.
4.  Click **OK**.
