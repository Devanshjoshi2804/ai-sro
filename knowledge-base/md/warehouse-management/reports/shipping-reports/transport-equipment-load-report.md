# Transport Equipment Load report

This report displays information about a load, including stop and shipment information. You can limit the information that displays by entering the LPN, carrier, transport equipment, or yard location.

The report includes the following general details:

-   LPN
-   Carrier name
-   Document number
-   Pro number
-   Transport equipment number
-   Transport equipment ID
-   Transport equipment status
-   Yard location

The report is ordered by break stop sequence code then by stop sequence and is divided into the following sections:

-   Stops
-   Shipments

The stop information includes the following details:

-   Building, stop sequence, stop ID, and name of the customer at which the stop will be made
-   Document number
-   Pro number
-   Ship-to address

The shipment information includes the following details:

-   Shipment ID
-   Shipping status
-   Document number
-   Pro number
-   Break stop sequence code
-   LPN
-   Storage location
