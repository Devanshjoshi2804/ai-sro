# Over, Short and Damaged Receiving report

This report lists the planned inbound order lines that have discrepancies. It also shows information about the discrepancies, such as expected quantities, received quantities, and received quantities of damaged inventory.

**Note**: This report is only available if receiving discrepancies exist for the transport equipment.

In the web client, you can configure the inventory statuses that you consider damaged and want to include in the damaged inventory quantities.

You can limit the report by inbound shipment, transport equipment, client, planned inbound order, supplier, carrier, and date range.

The report includes the following details:

-   Inbound shipment
-   Shipment status
-   Distribution identifier
-   Supplier
-   Receipt date
-   Transport equipment
-   SCAC code
-   Planned inbound order
-   Planned inbound order status
-   Order
-   Customer
-   Planned inbound order type
-   Document number
-   Order line
-   Item
-   Expected quantity
-   Receive quantity
-   Damaged quantity
-   Unit of measure
-   Expected (inventory) status
-   Expected catch quantity
-   Receive catch quantity
-   Damaged catch quantity
-   Catch unit type
