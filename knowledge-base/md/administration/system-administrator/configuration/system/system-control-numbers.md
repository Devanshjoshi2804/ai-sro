# System Control Numbers

A system control number is a unique identifier that is automatically generated and assigned to an individual entity, such as an appointment, count batch, or LPN. For example, when you add a new appointment, the application uses the system control number configuration to assign a unique identifier to the appointment. This identifier may not be displayed to the user, but is used by the application to track the unique occurrence of the appointment until the appointment is deleted.

A system control number configuration defines the format and sequence in which a system control number is automatically assigned to an entity.

You use the System Control Numbers page to configure the format and contents of system-assigned control numbers. The control number value is made up of the individual values for each of the control number sections.

**Note**: You can only change the format and content of control numbers generated by Warehouse Management.

## Modify a system control number

1.  Select **System Administrator > Configuration > ** **System > System Control Numbers**.
2.  In the grid, select the check box next to the control number, and then from the **Actions** drop-down list, select **Edit**.
3.  Enter information in the [System Control Numbers fields](#System_Control_Numbers_fields).
4.  Click **Apply**.

## System Control Numbers fields

 
| Field | Description |
| --- | --- |
| Control Number | System control number code. |
| Prefix | Characters that precede the generated sequence number. To indicate a constant value, enclose the characters in quotation marks, such as "BATCH". Leave this field blank when not using a prefix. |
| Prefix Length | Length of the prefix added before the number. This value must match the number of characters of the prefix. The default value is 0 if the field is left blank. |
| Last Sequence Number | The last sequence number that was used. The next number will be incremented by one. This field is display only. |
| Ensure Sequential Order Flag | Indicates that the next value is the next sequential number (the last sequence value incremented by one). If this field is clear, then the next number in the sequence is determined by the database sequence. |
| Sequence Length | Length of the sequence number to be generated. The number is left padded with zeros to meet this length. |
| Suffix | Characters to be added to the end of the sequence number. |
| Suffix Length | Length of the suffix, if defined. The default value is 0 if the field is left blank. |
| Base 36 Flag | Indicates that base 36 numbering system values (using 0 through 9 and A through Z) can be used to specify more possible values in a 6-character field. |
| Prefix Rollover Flag | Indicates that the prefix is incremented when the sequential numbers run out. |
