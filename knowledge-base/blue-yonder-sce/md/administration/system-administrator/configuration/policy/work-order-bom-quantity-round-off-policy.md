# Work order BOM quantity round off policy

The Work order BOM quantity round off (WORK-ORDER-PROCESSING/MISCELLANEOUS/WORK-ORDER-BOM-QTY-ROUND-OFF) policy determines if the values for the **Total Consumed Quantity** and **Reported Consumed Quantity** in the work order details are rounded to the nearest integer during work order processing. The **Total Consumed Quantity** and **Reported Consumed Quantity** values are rounded when the policy is enabled.

You use Policy Maintenance - Override to maintain the Work order BOM quantity round off policy.

You can configure the following DETAILS field for this policy:

-   **Return Number 1**: Specifies whether the policy is enabled. A value of 1 is enabled, 0 is disabled. The policy is disabled by default.
