# Third-party logistics policy

The Third-party logistics (THIRD-PARTY-LOGISTICS/INSTALLED/INSTALLED) policy indicates whether the application is running third-party logistics.

**Note**: For Warehouse Management, if this policy is enabled, the user will need to enter the client name when using Warehouse Management applications.

You use Policy Maintenance or Policy Maintenance - Override to maintain the Third-party logistics policy.

You can configure the following DETAILS field for this policy:

-   **Return Number 1**: Specifies whether the policy is enabled. A value of 1 is enabled, 0 is disabled. This policy is disabled by default.
