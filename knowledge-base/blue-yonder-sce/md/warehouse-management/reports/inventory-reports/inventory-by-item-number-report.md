# Inventory by Item Number report

This report displays detailed inventory information on all pickable locations for inventory in your warehouse. Each item is grouped by item client, building, and zone. You can limit the information by item, lot, revision level, origin code, inventory status, units per pack, units per case, size, four-wall inventory, and picked inventory.

The report includes the following details:

-   Item client
-   Item and item description
-   Building
-   Area
-   Storage location
-   Lot
-   Revision
-   Origin code
-   Inventory status
-   Unit quantity
-   Unit quantity grand total
