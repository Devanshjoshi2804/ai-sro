# Bill of Materials report

This report displays all detailed information about the items required to complete a specified bill of material (BOM). You can limit the information that displays by entering a specific BOM, client, or both before you generate the report. If no BOM is specified, the report displays information for all BOMs defined in the application.

The report includes the following details about the top-level item of the BOMs:

-   Bill of material number
-   Item
-   Client
-   Item client
-   Inventory status
-   Minimum quantity
-   Production tolerance (%)
-   Lot
-   Revision level
-   Origin code
-   Bill of material code
-   Until date
-   Auto-generate work order
-   Component tracking
-   Exclusively occupy production line
-   Work order type
-   Processing area
-   Production line

The report includes the following details for the BOM components:

-   Bill of material line number
-   Item
-   Item client
-   BOM quantity
-   Lot
-   Origin code
-   Revision level
-   Supplier
-   Inventory rotation
-   Date window
-   Footprint code
-   Units per case
-   Units per pack
-   Skip allocation
-   Over-allocation code
-   Over-allocation amount
-   Inventory status progression
-   Production station
-   Minimum shelf life
-   Date window unit
