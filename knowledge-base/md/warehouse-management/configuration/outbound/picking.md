# Picking - Configuration

Picking configurations define the attributes and behavior of the following options:

-   Release of pick work so that users can perform the required picks
-   Label printing
-   Cancellation of released pick work
-   Bulk picking inventory to fulfill multiple order lines with a single pick
-   Picking cartonization
-   Picking from a work assignment (list of multiple picks)
-   Pre-validation of inventory in the source location prior to directing the operator to pick from the location
-   Pick methods that determine the type of pick that is allocated from a location
-   Inventory attributes that an operator must confirm when performing a pick
-   Picking using a voice device
-   Picking using an RF device
