# Work with filters

You can use filters to limit the display of information. You can also save and manage filters to improve efficiency.

## Filter information on a page

When you open a page that displays a filter field, you can filter the display of information using one or more of the following options: a saved filter, the filter field, and if available, the **Quick Filters** field. However, selecting a saved filter replaces the filter criteria.

1.  Open a page that has a filter field.
2.  Perform any of the following tasks to filter the display of information:
    -   To select a saved filter, click **Load Saved Filter** ![Load Saved Filter](../../images/resources/images/image933578.png), and then select the filter.
    -   To define criteria using the filter field:
        1.  In the filter field, enter a value by which to limit the display. A drop-down list of attributes (such as grid column names) is displayed.
        2.  From the drop-down list, select the attribute to which the value applies. The criteria is displayed in the filter area, and the page displays the records that match the criteria.
        
        **Note**: You can repeat these steps to add criteria to the ad-hoc filter.
        
        4.  To remove criteria from the filter area, next to the filter criteria, click **Delete** ![Delete](../../images/resources/images/image895478_11x10.png). The page displays the records that match the remaining criteria.
    -   To define criteria using a quick filter, from the **Quick Filters** drop-down list, select a filter.
    -   To define criteria by entering multiple values in a filter:
        1.  Click the filter field, and then click **Filter using multiple fields**.
        2.  Enter a value in one or more attributes fields.
            
            **Note**: A value is required in every field that has an asterisk.
            
        3.  Click **Search**.
3.  To clear the filter from a page, in the filter area, click **Close** ![Close](../../images/resources/images/image895478_11x10.png).

## Save a filter

You can save a filter for future use or to share with others.

1.  Open a page that has a filter field.
2.  [Filter information on the page](#Filter_information_on_a_page).
3.  In the filter area, click **Save**.
4.  In the **Filter Name** field, enter the value.
5.  To share a filter with other users, select the **Share Filter** check box.
6.  Click **Save**. The filter is saved and is available for use when you click **Load Saved Filter** ![Load Saved Filter](../../images/resources/images/image933578.png).

## Modify a saved filter

1.  Open a page that has a filter field.
2.  Click **Load Saved Filter** ![Load Saved Filter](../../images/resources/images/image933578.png), and then select the filter.
3.  If the filter criteria is not already displayed, click **Show Criteria**.
4.  To add a value to the filter, use the filter field or, if available, select a quick filter. See [Filter field entries](filters.md) and [Quick filters](filters.md).
5.  To modify an attribute in the filter, click the attribute, and then select a new value.
6.  To modify a value in the filter, click the value, and then enter a new value.
7.  To modify the operator in the filter, click the operator, and then from the drop-down list, select a new operator.
8.  To delete a value from the filter, click **Delete** ![Delete](../../images/resources/images/image895478_11x10.png).
9.  To copy a saved filter:
    1.  From the **More** drop-down list, select **Save As**.
    2.  In the **Filter Name** field, enter the name for the new filter.
    3.  To share a filter with other users, select the **Share Filter** check box.
    4.  Click **Save**.
10.  To rename a saved filter:
     1.  From the **More** drop-down list, select **Rename**.
     2.  In the **Filter Name** field, enter the new name.
     3.  Click **Save**.

## Manage filters

1.  Open a page that has a filter field.
2.  Click **Load Saved Filter** ![Load Saved Filter](../../images/resources/images/image933578.png), and then select **Manage Filters**.
3.  To manage favorite saved filters:<br>
    
    **Note**: When you create and save a filter on a page, it is saved as a favorite. You can remove filters from favorites, and then add them again. You can also add filters shared by other users to your list of favorites.
    
    1.  Click **All Filters**. The filters that you created and filters that are shared by other users are displayed.
    2.  To set a filter as a favorite, click ![Not a favorite](../../images/resources/images/image933790_12x11.png). The icon updates to ![Favorite](../../images/resources/images/image942485.png).
    3.  To set a filter as not a favorite, click ![Favorite](../../images/resources/images/image942485_12x12.png). The icon updates to ![Not a favorite](../../images/resources/images/image933790.png).
4.  To assign a default saved filter:<br>
    
    **Note**: When you open a page that has a default filter, the information is pre-filtered based on the criteria defined for the default filter. You can assign only one default filter to a page.
    
    1.  Select **My Filters**.
    2.  In the grid, select the check box next to the filter, and then click **Set As Default**. The **Default Filter** label is displayed under the filter name.
    3.  To unassign the default filter, in the grid, click ![Remove](../../images/resources/images/image895478_9x8.png) on the **Default Filter** label for the filter. The label is removed.
5.  To share a saved filter with other users:<br>
    
    **Note**: When you share a filter, then all users accessing the same web client can use the filter. However, if you delete a shared filter that you created, then all users lose access to it. You can user filters other users have shared, but you can only modify or delete only the filters that you created.
    
    1.  Select **My Filters**.
    2.  In the grid, select the check box next to the filter, and then click **Share**. The **Sharing** label is displayed under the filter name
    3.  To stop sharing a filter, in the grid, click ![Remove](../../images/resources/images/image895478_11x10.png) on the **Sharing** label for the filter. The label is removed.
6.  Click ![Close](../../images/resources/images/image524298.png).

## Delete a saved filter

You can only delete the filters that you created; you cannot delete filters shared by other users. If you delete a shared filter, all users lose access to it.

1.  Open a page that has a filter field.
2.  To delete a filter using the Manage Filters window:
    1.  Click **Load Saved Filter** ![Load Saved Filter](../../images/resources/images/image933578.png), and then select **Manage Filters**.
    2.  Select **My Filters**.
    3.  In the grid, select the check box next to the filter, and then click **Delete**. A confirmation message is displayed.
    4.  Click **Yes**.
    5.  Click ![Close](../../images/resources/images/image524298.png).
3.  To delete a filter using the filter favorites list:
    1.  Click **Load Saved Filter** ![Load Saved Filter](../../images/resources/images/image933578.png), and then from the drop-down list, select the filter.
    2.  From the **More** drop-down list, select **Delete**. A confirmation message is displayed.
    3.  Click **Yes**.
