# Waves and Picks

The Waves and Picks page is accessible from the following modules: **Outbound Planner**, **Picking**, or **Production**.

This page provides visibility to existing waves and the picks associated with the waves. Additionally, you can plan orders and shipments into new waves, as well as perform actions on pick work. A wave is used in the application to allocate inventory for outbound orders and shipments.

When you first access the page, if you want to manage or view information for existing waves or picks, you must enter search criteria to retrieve the data. Alternatively, you can limit the number of records that are displayed by selecting a quick filter.

This page includes the following tabs:

-   **Waves**: Use the Waves tab to view the waves that match your search criteria and to perform actions for manual wave processing. The number of waves that match the search is displayed on the tab. When you click the identifier for a wave, additional wave details are displayed as well as tabs that provide visibility to the following information:
    -   Orders in the wave
    -   Shipments in the wave
    -   Loads in the wave
    -   Picks associated with the wave
    -   Short inventory in the wave
    -   Pending replenishments for the wave
    -   Cross-dock opportunities for the wave

For more information, see [Waves](../outbound-planner/outbound-planning-concepts.md).

-   **Picks**: Use the Picks tab to view the pick work that matches the search criteria. You can also perform pick-related tasks for manual wave processing, such as releasing picks, canceling picks, and changing the priority of picks. If you expand a work assignment, bulk pick, or carton pick, the picks associated with the assignment or carton are displayed. If you click on the identifier for a work assignment, additional details are displayed and you can perform tasks specific to the work assignment.
