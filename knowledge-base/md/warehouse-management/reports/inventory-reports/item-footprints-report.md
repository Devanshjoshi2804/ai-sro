# Item Footprints report

This report displays the item footprints identified in the application. Item footprints are used to designate the packaging dimensions of items within your facility.

The report includes the following details:

-   Item
-   Nesting dimensions (height, length, and width)
-   Pallet stack height
-   Footprint code and description
-   Item client
-   Default handling unit type (if handling unit tracking is enabled for the inventory category)
-   Default item footprint flag
-   Cases per tier
-   Footprint details for each unit of measure (UOM) including:
    -   Unit quantity
    -   Length, width, and height (in inches)
    -   Gross and net weight (in pounds)
    -   Whether the UOM:
        -   Can be cartonized
        -   Represents the pallet, case, inner pack, or stocking UOM
        -   Is the default receiving UOM
        -   Must be placed in a carton during the distribution process
    -   Threshold picking percentage
