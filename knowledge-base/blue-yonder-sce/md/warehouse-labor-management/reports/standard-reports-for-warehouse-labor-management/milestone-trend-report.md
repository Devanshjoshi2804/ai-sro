# Milestone Trend report

This report provides a graphical view of historical trend data from metrics used in report cards, such as for user performance, that are measured against particular milestone types, such as Training or Observation. This report gives average scores across all users for the report card calculation points from the milestone date. For example, you can select a training milestone and a performance-related report card for a user. After setting the number of report card calculations before and after the milestone occurred, you can run the report and see how the training impacted performance.

After you select the report, you can provide a description of the report, specify the date range for which information is collected, and enter selection criteria to group or limit the output of the report.

## Milestone Trend report fields

 
| Field | Description |
| --- | --- |
| Group By (1–3) | Grouping level by which the information is organized (for example, by supervisor or user). You can have up to three levels of grouping. |
| Date Range | Date range for the information that is included in the report. You can select a date that is relative to today's date (such as Yesterday, Last Week, or Last Year) or you can enter a custom date range. |
| From Date | Starting date for a specific date range. |
| To Date | Ending date for a specific date range. |
| Supervisors | Person to whom a user reports. A supervisor manages and oversees a user's work. You can also use the supervisor's ID for easy user selection in reports, assignments, performance statistics, report cards, and payroll information. |
| Users | Unique identifier for an individual who will be using the application, either with direct access or through an internet connection. |
| Warehouse | Unique identifier associated with the warehouse. In a multi-warehouse environment, you can select the warehouse for which you are authorized. |
| User Groups | Optional category into which users can be grouped for easy selection in reports, assignments, performance statistics, report cards, and payroll information. |
| Work Teams | Optional category into which users can be grouped for easy selection in reports, assignments, performance statistics, report cards, and payroll information. |
| Report Groups | Optional category into which users can be grouped for easy selection in reports, report cards, and payroll information. |
| Milestone Type | Significant operation-specific event in a person’s employment, such as completion of a training course, a certification requirement, a coaching session, an observation, or a reprimand, which could have an impact on a user's performance against metrics. |
| Milestone Subtype | Subtype that is associated with the selected milestone type. |
| Report Card | Unique identifier for the report card. A report card is part of a customized incentive or disciplinary program within your facility. |
| \# Calculations Before | Number of report card calculations to include in the generated report that occurred before the milestone event. (This setting is independent from the date range for the report.) For example, if the report card is calculated weekly and you set the **\# Calculations Before** to 2, the report will include two weeks worth of calculations. If the report card is calculated monthly and you set the **\# Calculations Before** to 2, the report will include two months worth of calculations. |
| # Calculations After | Number of report card calculations to include in the generated report that occurred after the milestone event. (This setting is independent from the date range for the report.). For example, if the report card is calculated weekly and you set the **\# Calculations After** to 2, the report will include two weeks worth of calculations. If the report card is calculated monthly and you set the **\# Calculations After** to 2, the report will include two months worth of calculations. |
| Subtitle | Additional descriptive information that will be displayed below the title in the generated report. |
