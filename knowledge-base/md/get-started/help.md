# Help

Help provides conceptual, procedural, and field-level information to help you work with the functions in the application.

The Help provides the following components to help you locate information:

-   **Contents**: Displays a list of pages organized by functional area. Each page contains the following help components:
    -   Conceptual topics
    -   Procedural topics
    -   Field description topics
-   **Search**: Enables you to perform a full-text search for a specific word or phrase.

When you have located the information that you want, you can copy selected text or print the entire topic directly from the Help.

## Conceptual topics

Conceptual topics provide theory and background information that helps you understand the context in which procedural information fits. Conceptual topics support learning about the tasks that you want to perform and the goals that you want to accomplish. For example, they may explain why you must do something in a particular manner or provide details to help you make decisions.

## Procedural topics

Procedural topics describe the steps required to complete a specific task. The goal of procedural information is to walk you through the successful and immediate completion of a task.

Procedures typically include the following types of steps:

-   Steps that you must perform to complete the procedure
-   Optional steps that you can perform based on a specific need or circumstance, but which are not required to complete the procedure
-   Steps that provide multiple options and require you to perform one or more of the options

## Field descriptions

A field description describes the purpose of a field, the type of information required, and when required, a basic level of instruction. A field description is written for each field that is displayed on a page or window.

Within the Help, field descriptions are easily accessible. From each procedure either a link to a topic that lists the field descriptions (for more than three fields) or a description of the fields in an applicable step (for three or fewer fields) is provided. You can also use the search functionality in the Help to access the field descriptions.

## Slide-out help

Slide-out, or context-sensitive help, is available for select fields within a page to provide immediate information that describes the purpose of a field, the type of information required, and when required, a basic level of instruction. Slide-out help is available for a field when an information ![Help](../../images/resources/images/image640155_13x13.png) icon is displayed next to it. When you click ![Help](../../images/resources/images/image640155.png), a help panel slides out from the right side of the web client window. The slide-out help remains open until you close it or navigate to another page.

## Search for content

You can use the **Search** field in the Help's header to search for content.

You can use the following options to search for words or phrases in the **Search** field:

  
| Search object | Example | Result |
| --- | --- | --- |
| A single word | Select | Topics that include the word "select", including variations such as "selector" and "selection" |
| A phrase | "new operator" | Topics that include the literal phrase "new operator" and grammatical variations such as "new operators" |
| new operator | Topics that include the words "new" and "operator" in addition to the phrase "new operator" |
| Multiple terms in the same topic | ship rate<br > ship AND rate<br > ship & rate<br > ship + rate | Topics that include both the words "ship" and "rate" as well as variations of the words, such as "shipping" and "rated" |
| Separate terms in a topic | domestic OR foreign<br > domestic | foreign | Topics that include either the word "domestic" or the word "foreign" or both words |
| One term without another term | product NOT regular<br > product ! regular | Topics that include the word "product" but not the word "regular" |

The following rules apply when you search:

-   Searches are not case-sensitive, so you can enter your search in uppercase or lowercase characters.
-   You can search for any combination of letters (a–z) and numbers (0–9). However, a minimum of three characters must be provided to return a result.
-   The default operator for multiple word search expressions is AND. For example, if you enter Main Menu as a search term, you create the logical equivalent to "main AND menu" for the search.

When you submit a search request, the search results are displayed in the main content window. You can click a topic's heading to display the topic.

### Filter the search

When enabled within your Help, you can use search filters to limit the topics that are searched for your specified search content. This option can reduce the number of topics that are returned by the search.

1.  In the header, click ![Filter](../../images/resources/images/skin/filter_gray_20x20.png) next to the search field. A list of search categories is displayed.
2.  Select the category to filter the search.
3.  Enter the search term in the **Search** field.
4.  Click ![Search](../../images/resources/images/skin/search_gray_20x20.png). The resulting search topics are displayed.
