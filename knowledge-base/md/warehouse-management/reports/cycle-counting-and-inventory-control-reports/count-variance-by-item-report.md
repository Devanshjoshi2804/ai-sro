# Count Variance (by Item) report

This report displays, by item, cycle counts that were performed and for which the amount counted did not match what the application expected. You can limit the report by item and item client.

The report includes the following details:

-   Item
-   Item description
-   Item client
-   Count batch
-   Count date
-   Storage location
-   Lot
-   Expected quantity
-   Unit of measure
-   Count quantity
-   Variance
-   Total counts completed
-   Grand total
