# Picking

The Picking functionality provides visibility into outstanding pick work and the ability to manage the picks and any picking issues that occur. The picking process consists of finding and selecting inventory in the specified quantity from a location and delivering the inventory to its assigned destination location in the warehouse to fulfill an order. Picking can be performed by operators using an RF device, a voice recognition device, or a paper-based process in which picks are confirmed at a workstation.

For more information and setup tasks, see the [Picking](configuration/outbound/picking.md) configurations.

The application supports the creation of work assignments for orders, work orders, and replenishments. If the inventory handling unit category is enabled for your warehouse, you can perform work assignments to specific handling units or specific slots on a handling unit.
