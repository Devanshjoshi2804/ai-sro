# States

You use the States page to associate a state with an abbreviation, as well as modify or delete those associations.

## Add or modify a state code

1.  Select **System Administrator > Configuration > ** **Internationalization > States**.
2.  Perform one of the following tasks:
    -   To add a new state code, from the **Actions** drop-down list, select **Add**.
    -   To copy a state code, in the grid select the check box on the row of the state, and then from the **Actions** drop-down list, select **Copy**.
    -   To modify a state code, in the grid select the check box on the row of the state, and then from the **Actions** drop-down list, select **Edit**.
3.  Enter information in the [States fields](#States_fields).
4.  Click **Save**. A confirmation message is displayed.
5.  Click **OK**.

## Delete a state code

1.  Select **System Administrator > Configuration > ** **Internationalization > States**.

1.  In the grid, select the check box on the row of the state.
2.  From the **Actions** drop-down list, select **Delete**. A confirmation message is displayed.
3.  Click **OK**.

## States fields

 
| Field | Description |
| --- | --- |
| **State** | Code of the state. |
| **Country** | Code of the country. |
| **Group Name** | Identifier used by Blue Yonder product teams to indicate the product group that was responsible for loading data (in a particular row of a table). For example, standard group names include dcs\_data, mcs\_data, sal\_data, and so on. This field is display only. |
| **Country Description** | Name of the country. |
| State Description | Name of the state. |
